loft
====

Menu-bar client. Overlay inside TLS, protocol loft/1.0.
macOS 10.13 or later.

Install
  Drag loft onto Applications.
  Open loft from Applications. It lives in the menu bar (top right).

First connect
  macOS asks for an administrator password so loft can create the
  tunnel and, if you turn Hold on, take the default route.
  Reset routes restores the original default.

Profiles
  Menu → Open loft… to import a .loft file or client.yaml.

If macOS says the app is from an unidentified developer
  Control-click loft → Open. Signed Developer ID builds skip this.

---

Клиент в строке меню. macOS 10.13+.

Установка
  Перетащите loft на Applications.
  Откройте loft из Applications — значок в правой части строки меню.

Первое подключение
  Система спросит пароль администратора (туннель и маршрут).
  Hold держит маршрут, пока loft жив. Reset routes возвращает как было.

Профили
  Меню → Open loft… — импорт .loft / client.yaml.

Если Gatekeeper ругается (локальная ad-hoc сборка)
  Control-клик по loft → Открыть.
