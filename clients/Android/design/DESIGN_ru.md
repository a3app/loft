# loft · клиент Android

[English](DESIGN.md) · **Русский** · [中文](DESIGN_zh.md)

Приложение и `VpnService`. Марка, палитра и Avenir Next: [`brand/`](../../../docs/brand/). Интерактивный макет: [`index.html`](index.html); у каждого состояния своя ссылка, например `index.html#edit-sstp`, `#settings-route`, `#home-off` (адрес меняется по мере кликов). Контейнер Java в [`../app/`](../app/). Живая сессия — Go внутри `LoftVpnService`, не `loft-front`. Тонкий хост уже вставляет YAML; этот макет — GUI, который заменит экран вставки.

## 1. Продукт

Локальный вход — системный VPN (`VpnService`). Один профиль сразу: loft (`lt_…`, пароля нет), SSTP (логин + пароль), VLESS (`vless://`) или Trojan (`trojan://`).

v1: именные подключения на диске, импорт/экспорт `.loft`, Подключить/Отключить, удержание (системными тумблерами Android), раздельная маршрутизация по спискам протокола. `select: auto` внутри YAML loft. Туннель один.

Файл `.loft` держит **одно или несколько подключений**. Типы смешиваются: `loft`, `sstp`, `vless`, `trojan`. В строке списка — хост и **тип · транспорт** (`loft · get`). Адрес loft — строка `loft://`. Спецификация: [docs/share_ru.md](../../../docs/share_ru.md).

Поделиться: сканер QR или файл/картинка с `loft://`, `sstp://`, `vless://`, `trojan://` или `.loft`.

Настройки Android показывают ту же строку VPN, которую поднимает приложение. Приложение не подменяет Настройки.

Язык адаптера — **Java 17**. gomobile уже отдаёт Java; Kotlin runtime в этот процесс не грузим. Макет — HTML; живой GUI позже на Views (без Compose).

Android TV / Google TV — тот же `VpnService` и AAR, flavor Leanback. Не этот макет; [план](../PLAN_ru.md) фаза 4. VIDAA / Tizen / webOS вне рамок.

### Раздельная маршрутизация

Модель macOS (DESIGN macOS §5): **зона** идёт через loft или в обход, **сервис** (имя + CIDR) только принадлежит зоне, **исключение** — CIDR, который не входит в зону и сохраняется при обновлении списка. Встроенные зоны Local (в обход, LAN) и Global (через, `global.bat`), свои — из редактора. На Android «через loft» — маршруты `VpnService.Builder.addRoute`, «в обход» — `excludeRoute` (Android 13+); на старых версиях «в обход» вычитается из маршрутов туннеля. Пока туннель выключен, всё и так идёт напрямую.

Вход: Настройки → Маршрут → тумблер и золотая **Списки**. Экраны открываются внутри вкладки Настройки, вверху **←**. Экраны те же, что на iOS: Списки (тумблер, вкладки зон с числом сервисов, строка `Global · Через loft`, поиск, строки сервисов, **+ Добавить**, Импорт · Экспорт · Репозиторий), Сеть (Маршрут / Исключение, сети, сервис, зона), Зоны, Зона (имя, направление, адрес списка + **Списки**, автообновление; своя — Удалить зону, сервисы → Global), Репозиторий, Каталог (Мир, Россия, Китай, Иран, Казахстан, Беларусь), Импорт (из файла через SAF), Экспорт (все зоны в одном файле loft-routes, лист «Поделиться»; формата Keenetic .bat нет).

## 3. Хром Android

Не перекрашивать Настройки → Сеть и интернет → VPN. Макет показывает, как **loft** выглядит в *их* списке VPN: статус Подключено, тумблер — системный туннель, не второй выключатель в нашем приложении.

Подключить вызывает `VpnService.prepare` один раз, затем `startForegroundService(LoftVpnService)`. Если пользователь выключил loft в Настройках, приложение показывает выкл.

Разрешение VPN — системный диалог **Запрос подключения** один раз. Дальше Подключить не спрашивает.

Разрешение камеры — системный лист при первом Сканировать. Галерея — системный Photo Picker (без широкого доступа к медиа). SAF: картинки, текст, YAML, `.loft`.

Фильтр intent `loft`: тап по `loft://…` предлагает импорт. Файлы `.loft` открываются тем же детектором.

### Жесты списка

| Жест | Действие |
|------|----------|
| Тап | Открыть подключение (Правка). Подключает компактная кнопка Подключить; если жило другое подключение, оно сначала отключается. |
| Свайп влево | Удалить, с диалогом подтверждения. |
| Свайп вправо | Править. |
| Долгое нажатие | Меню: Править; Экспорт `.loft`, если строка выбрана; Удалить. |
| Экспорт | Лист: это подключение как `Name.loft`; QR `loft://` живого фронта; все подключения как `Family.loft`. |

Живая сессия — **foreground service** (тип `connectedDevice`). В уведомлении: имя, тип · транспорт · IP оверлея, Отключить. На API 33+ один раз ещё лист разрешения уведомлений.

**Без VPN — без интернета** на Android — системные тумблеры **VPN всегда включён** и **Блокировать подключения без VPN**. Приложение открывает эту страницу Настроек; тумблеры щёлкает пользователь.

Плитка быстрых настроек: один тап Подключить/Отключить активного профиля. Лампа горит = в сети.

## 4. Визуал

Те же токены, что на iOS и macOS: Ink `#1A1714`, Lamp `#E8B84A`, Paper `#E8DFD2`, Avenir Next. Хром приложения — loft (тёмная бумага), не сиреневый Material You; компоненты — Material: нижняя панель навигации (активная вкладка — капсула лампы под иконкой), верхняя панель с «←» / «✕» и меню ⋮, FAB 56 dp со скруглением 16 dp, нижние листы и диалоги.

Шрифт: заголовки Demi, текст Regular, ключи Roboto Mono. В сети = окно лампы горит. Выкл = лампа погашена, каменная L.

Системные поверхности в макете (Запрос подключения, Настройки → VPN, уведомление, плитка) оставляют системный хром Android, чтобы была видна граница продукта.

## 5. Тексты
