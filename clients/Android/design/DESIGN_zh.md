# loft · Android 客户端

[English](DESIGN.md) · [Русский](DESIGN_ru.md) · **中文**

手机应用加一个 `VpnService`。标志、色板、Avenir Next：[`brand/`](../../../docs/brand/)。交互模型：[`index.html`](index.html)；每个状态都有自己的链接，比如 `index.html#edit-sstp`、`#settings-route`、`#home-off`（点到哪儿地址就跟到哪儿）。协议：[docs/protocol_zh.md](../../../docs/protocol_zh.md)。导入 URI：[docs/share_zh.md](../../../docs/share_zh.md)。

Java 容器在 [`../app/`](../app/)。活会话是 `LoftVpnService` 里的 Go，不是 `loft-front`。应用按这个模型做：主页 / 连接 / 编辑 / 扫描 / 设置。

---

## 1. 产品

入站是系统 VPN（`VpnService`）。一次一条配置：loft（`lt_…`，没有密码）、SSTP（用户 + 密码）、VLESS（`vless://`）或 Trojan（`trojan://`）。

v1：磁盘上的命名连接，导入/导出 `.loft`，连接/断开，无 VPN 时禁止联网（用 Android 系统开关），按协议列表分流。loft YAML 里 `select: auto`。一次一条隧道。

`.loft` 文件里是 **一条或多条连接**。类型可以混：`loft`、`sstp`、`vless`、`trojan`。列表行显示主机和 **类型 · 传输**（`loft · get`）。loft 地址是字符串 `loft://`。规格：[docs/share_zh.md](../../../docs/share_zh.md)。

分享：扫二维码，或载入带 `loft://`、`sstp://`、`vless://`、`trojan://` 或 `.loft` 的文件/图片。

Android 设置里显示的就是应用拉起的那条 VPN。应用不替代设置。

适配器语言是 **Java 17**。gomobile 已经吐 Java；这个进程不装 Kotlin runtime。模型是 HTML；后面的 GUI 是 Views（不用 Compose）。

Android TV / Google TV 是同一个 `VpnService` 和 AAR，加 Leanback flavor。十英尺模型：[`tv/`](tv/)。VIDAA / Tizen / webOS 不做。

## 2. 屏幕

和 iOS、macOS 一样的几个屏，用 Material 外壳：底部导航栏，顶栏带「←」或「✕」，FAB，底部弹出页。系统返回在哪儿都等于「←」。

| 屏 | 内容 |
|----|------|
| 主页 | 标志、`loft`、状态胶囊（点一下 → 列表）、大按钮连接 / 断开。关着：胶囊「未连接 · Home ›」。连接中：胶囊「正在连接: Home…」，按钮 **取消**，火花「握手」。卡片随协议变化 —— loft：**协议** loft/1.0 · **前置** GET（没连上时「自动」）· **选项** mux · mask；SSTP：**协议** · **传输** PPP · **认证** CHAP；VLESS：**协议** · **传输** TCP · **安全** REALITY；Trojan：**协议** · **传输** TCP · **安全** TLS。左边是近一分钟的速度图，当前 ↓（灯色）和 ↑（石色）靠窗口右边对齐。设置 → **速度图**：**曲线**（默认；平滑的 ↓ 曲线带柔和灯色填充，细的 ↑ 线，最新值上一个点）或 **柱形**（两行细圆角柱，越旧越淡）。简化界面没有卡片和火花；点卡片弹出 **详细信息**（loft 网络地址、前置、MTU、服务器）。下面，连着时有 **外部 IP**、**Overlay IP** 和 **路由**（网关）三行，和 macOS 弹出层一样（简化界面没有）。下面是导航栏。 |

### 分流

沿用 macOS 的模型（macOS DESIGN §5）：**区域** 经 loft 或绕过 loft，**服务**（名称 + CIDR）只是属于某个区域，**排除** 是不写入路由、拉取列表后仍保留的 CIDR。内置区域 Local（绕过，局域网）和 Global（经 loft，`global.bat`），自己的区域在编辑器里加。Android 上「经 loft」是 `VpnService.Builder.addRoute`，「绕过」是 `excludeRoute`（Android 13+）；老版本从隧道路由里减掉。隧道关着时本来就全部直连。

入口：设置 → 路由 → 开关和金色的 **列表**。这些屏在设置标签里打开，顶上 **←**。屏和 iOS 一样：列表（开关、带服务数的区域标签、`Global · 经 loft`、搜索、服务行、**+ 添加**、导入 · 导出 · 规则集）、网络（路由 / 排除、网段、服务、区域）、区域、区域编辑（名称、方向、列表地址 + **列表**、自动更新；自己的区域能删，服务 → Global）、规则集、目录（全球、俄罗斯、中国、伊朗、哈萨克斯坦、白俄罗斯）、导入（通过 SAF 从文件）、导出（所有区域写进一个 loft-routes 文件，分享页）。

**清理。** 删除立即生效。底部 snackbar 显示 5 秒：「已删除：YouTube · **撤销**」，点撤销恢复原样。除清空区域和清空排除项外，不弹确认框。

- 在服务行上**向左滑动**，露出红色 **删除**。
- **长按**一行进入选择模式。标题换成操作栏：**✕**、「已选 N 项」、**全选**（打开的区域里所有服务，再点取消）、**删除**。各行出现勾选圆圈，点按切换。
- 在 **网络** 屏，已有条目底部有 **删除服务**（排除项为 **删除排除项**）。屏幕关闭，出现 snackbar。
- 列表导航栏的 **⋮**：**选择**（同一选择模式）和 **清空区域**。对话框「清空 Global？」：**仅自己添加的 (N)** 和 **全部，包括列表 (M)**。「全部」会解除区域的列表：地址和自动更新关闭，否则下次更新服务又会回来。排除项保留。区域里没有来自列表的服务时，只有一行 **全部删除**。

来自列表的服务（来源「列表」）删除时不会无痕消失：它的网段移入该区域的排除项，否则下次更新又会加回来（macOS §5 的规则）。snackbar 会写明：「… · 列表网络已移入排除项」。自己添加的服务直接删除。

**排除项**有单独的屏，不混在服务列表里。服务列表下方有一行 **排除项 · N ›**。「Global · 排除项」屏（顶上 **←**）：说明「这些网络不会加入路由，列表更新时也不会恢复」，每行一个 CIDR（等宽）、右侧是服务名，点按在网络屏编辑。**向左滑动** 露出 **恢复**：删除该排除项，网络会随下次列表更新回来。**+ 添加** 打开网络屏并选中「排除」。底部 **清空排除项**，带对话框。

## 3. Android 外壳

不重画 设置 → 网络和互联网 → VPN。模型展示 **loft** 在 *系统* VPN 列表里的样子：状态已连接，开关是系统隧道，不是我们应用里第二个开关。

连接时先调一次 `VpnService.prepare`，再 `startForegroundService(LoftVpnService)`。用户在设置里关了 loft，应用显示已关闭。

VPN 权限是系统的 **连接请求** 对话框，一次。之后连接不再问。

相机权限是第一次扫描时的系统页。相册用系统 Photo Picker（不要宽泛的媒体权限）。SAF：图片、文本、YAML、`.loft`。

intent 过滤 `loft`：点 `loft://…` 提示导入。`.loft` 文件走同一个识别器。

### 列表手势

| 手势 | 动作 |
|------|------|
| 点一下 | 打开这条连接（编辑）。连接靠紧凑的「连接」按钮；另一条开着的话先断开。 |
| 向左滑 | 删除，带确认对话框。 |
| 向右滑 | 编辑。 |
| 长按 | 菜单：编辑；选中的行有导出 `.loft`；删除。 |
| 导出 | 弹出页：这条连接 `Name.loft`；当前前置的二维码 `loft://`；全部连接 `Family.loft`。 |

活着的会话是 **前台服务**（类型 `systemExempted`，API 34+ 上的 VpnService 情形）。通知栏里：名称、类型 · 传输 · overlay IP、断开。API 33+ 还有一次通知权限页。

Android 上的 **无 VPN 时禁止联网** 就是系统的 **始终开启的 VPN** 和 **阻止不使用 VPN 的连接**。应用打开那页设置；开关由用户自己拨。

快捷设置开关：点一下连接或断开当前配置。灯亮 = 在线。

## 4. 视觉

和 iOS、macOS 同一套 token：Ink `#1A1714`、Lamp `#E8B84A`、Paper `#E8DFD2`、Avenir Next。应用外壳是 loft（深色纸），不是紫色的 Material You；组件用 Material：底部导航栏（当前标签是图标下的灯色胶囊）、带「←」/「✕」和 ⋮ 菜单的顶栏、56 dp 圆角 16 dp 的 FAB、底部弹出页和对话框。

字体：标题 Demi，正文 Regular，密钥 Roboto Mono。在线 = 灯窗亮。关 = 灯灭，石色 L。

模型里的系统界面（连接请求、设置 → VPN、通知栏、快捷开关）保留 Android 原生外壳，让产品边界看得见。
