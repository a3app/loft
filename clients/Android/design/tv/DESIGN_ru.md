# loft · Android TV / Google TV

[English](DESIGN.md) · **Русский** · [中文](DESIGN_zh.md)

Та же сессия, что на телефоне: `LoftVpnService` + AAR `clients/mobile`. Этот макет — оболочка для управления с дивана. Знак, палитра, Avenir Next: [`brand/`](../../../../docs/brand/). Интерактивный макет: [`index.html`](index.html); у каждого состояния своя ссылка, например `#home-on`, `#pair`, `#settings-route`. Макет телефона: [`../index.html`](../index.html). Протокол: [docs/protocol_ru.md](../../../../docs/protocol_ru.md). URI импорта: [docs/share_ru.md](../../../../docs/share_ru.md). Каталог: [README](../../README_ru.md).

Рабочий GUI позже будет на Leanback (Java 17 Views, пульт), без Compose. `connect` бывает только на ноде. Авто = GET.

---

## 1. Продукт

Приставка — это хост в гостиной. YouTube, Play Store и остальные приложения ходят через overlay, потому что у Android один системный VPN. Обычно приставка подключена по Ethernet, Wi-Fi — запасной канал. Смена пути (`NetworkCallback` → `NotifyPathChange`) сохраняет адрес в сети loft.

Одновременно активен один профиль: loft / SSTP / VLESS / Trojan. Именованные подключения на диске, импорт/экспорт `.loft`, Подключить / Отключить, удержание системными тумблерами «VPN всегда включён», раздельная маршрутизация как **маршрут по умолчанию + обход LAN**. Редактор списков CIDR остаётся на телефоне.

Flavor `tv` лежит в этом же дереве. `LEANBACK_LAUNCHER`, баннер 320×180, тачскрин не обязателен, Leanback обязателен. Отдельный `applicationId` из того же семейства, `app.loft.android.tv`, позволяет телефону и приставке ужиться на одном аккаунте Google.

В v1 камера на телевизоре не используется. Способы импорта: QR **на экране** (телефон сканирует телевизор), файл `.loft` с флешки или из Загрузок, ссылка, набранная с пульта.

VIDAA / Tizen / webOS / Roku в задачу не входят.

## 2. Экраны

Нижней навигации, FAB и свайпов нет. Слева рельс (Дом / Подключения / Настройки), справа содержимое. По умолчанию фокус стоит на главном действии. Системная кнопка Назад всегда возвращает на шаг.

| Экран | Что |
|-------|-----|
| Дом | Знак, `loft`, статус (лампа + имя профиля + аптайм). Большая **Подключить** / **Отключить**. Когда выключено, справа карточка профиля (имя, `тип · фронт`, хост). В сети: overlay IP, внешний IP, чип Ethernet/Wi-Fi, ↓ / ↑ двумя крупными числами — графика скорости нет, с дивана его не разглядеть. Во время подключения: **Отмена**, лампа в режиме ожидания. На пустой приставке вместо Подключить — три плитки добавления. |
| Подключения | Одна горизонтальная лента Leanback. Карточка: имя, `loft · get`, хост. У активного — кромка цвета лампы. Последняя карточка — **+**. OK на карточке делает её активной и возвращает на Дом. Под лентой: Править · Поделиться QR · Удалить. |
| Добавить | Три плитки одного размера: **QR на телевизоре** · **С флешки или из Загрузок** · **Набрать ссылку**. |
| Связка | На экране крупный QR и код из шести знаков (`K7M2P4`). Текст: на телефоне loft → На телевизор → навести камеру (или ввести код). Телефон отправляет YAML недолговечному слушателю в LAN. Назад отключает слушателя. |
| Поделиться QR | То же оформление, что у связки; в QR — `loft://` выбранного профиля. Телефон считывает ключ с экрана. |
| Файл | Диалог выбора Leanback для USB OTG и «Загрузок». `.loft`, `loft://`, YAML. В подтверждении: имя, тип · транспорт, хост; секрет скрыт. |
| Набор | Клавиатура Leanback. Поле `loft://` или YAML. **Добавить**. |
| Правка | Намеренно минимальная. Имя, чипы способа **Авто · GET · WS · H2 · QUIC · H3 · L3**, Сохранить. Полные формы loft / SSTP / VLESS / Trojan остаются на телефоне. Пульт — не инструмент для правки YAML. |
| Настройки | Группы **Общие / Маршрут / Подключение**. Общие: язык, расширенный журнал. Маршрут: маршрут по умолчанию, обход LAN, **Без VPN — без интернета** в виде ссылки **Открыть настройки VPN** (системные «VPN всегда включён» и «Блокировать подключения без VPN»). Подключение: подключаться при запуске, переподключаться при обрыве. Внизу: Журнал · О программе. Редактора списков CIDR нет. |
| Журнал | Последние строки, ключ показан сокращённым. Очистить — с подтверждением. |
| О программе | Знак, версия, loft/1.0 · SSTP · VLESS · Trojan, абзац, Made with love by A³. |
| Запрос | Системный **Запрос подключения** Android TV, один раз. Дальше Подключить ничего не спрашивает. |
| Системный VPN | Настройки → Сеть и интернет → VPN. Макет показывает loft в *их* списке. |
| Баннер | 320×180 для ряда Google TV / Play: тёмная бумага, знак L, слово `loft`, лампа горит, пока сессия активна. |

## 3. Пульт

| Клавиша | Действие |
|---------|----------|
| ← → | Рельс ↔ панель; вдоль ленты карточек. |
| ↑ ↓ | Иконки рельса; строки настроек; ряд действий под Подключениями. |
| OK | Элемент в фокусе. На Доме это Подключить / Отключить. |
| Назад | Шаг назад. Связка / QR / набор / файл / правка закрываются. На Доме — системный выход из Leanback. |

Фокус: кольцо цвета лампы 3 px, отступ 4 px, масштаб карточки 1.06. Минимальная зона нажатия 48 dp. Отступ от краёв под overscan — 48 dp. Заголовок ~34 sp, текст ~20 sp, подсказка ~16 sp на 1080p.

В макете на ноутбуке стрелки, Enter и Escape работают по этой таблице.

## 4. Импорт без камеры

| Путь | Когда |
|------|-------|
| QR на телевизоре | Телефон и приставка в одной LAN. Предпочтительный способ. |
| Код из шести знаков | Та же связка, если камеры нет и на телефоне. |
| Флешка / Загрузки | Флешка или файл, который оператор уже положил на приставку. |
| Набор `loft://` | Последний вариант. IME Leanback медленный; поле принимает вставку с Bluetooth-клавиатуры. |

Сканер на телефоне уже есть. На TV всё наоборот: QR показывает **экран**.

Hairpin, dual-stack, `protect(fd)`, FrontIP `excludeRoute` относятся к движку телефона. Этот макет их не перерисовывает.

## 5. Визуал

Те же токены, что на телефоне: Ink `#1A1714`, Lamp `#E8B84A`, Paper `#E8DFD2`, Avenir Next. Оформление TV — тёмная бумага loft во весь экран. Системные диалоги (Запрос подключения, Настройки VPN) сохраняют оформление OEM, чтобы была видна граница продукта.

В сети = окно лампы горит. Выкл = лампа погашена, каменная L. Сиреневого Material You нет. Нет ни нижней панели телефона, ни FAB, ни плитки быстрых настроек (на Android TV её не бывает).

## 6. Тексты

Общие кнопки берутся из `clients/macOS/lang/*.lang`. Строки, которые есть только на TV: три плитки добавления, связка, флешка, подсказки пульта. Формулировки — в привычном языке VPN для каждого языка.

| id | EN | RU |
|----|----|----|
| connect | Connect | Подключить |
| disconnect | Disconnect | Отключить |
| add_qr | Show QR on this TV | QR на телевизоре |
| add_usb | From USB or Downloads | С флешки или из Загрузок |
| add_type | Type the link | Набрать ссылку |
| pair_hint | Open loft on the phone → Send to TV | На телефоне: loft → На телевизор |
| remote_ok | OK — connect | OK — подключить |
| underlying_eth | Ethernet | Ethernet |

## 7. Вне этого макета

Карточка в Play для TV. RSS на приставке с 2 ГиБ оператор замеряет сам (About показывает VmRSS). Dist / VERSION не трогаем, пока не попросят. Flavor `tv`, Java Leanback, баннер и GUI для дивана лежат в `app/src/tv/`.
