# loft · Android TV / Google TV

[English](DESIGN.md) · **Русский** · [中文](DESIGN_zh.md)

Та же сессия, что на телефоне: `LoftVpnService` + AAR `clients/mobile`. Этот макет — оболочка с дивана. Марка, палитра, Avenir Next: [`brand/`](../../../../docs/brand/). Интерактивный макет: [`index.html`](index.html); у каждого состояния своя ссылка, например `#home-on`, `#pair`, `#settings-route`. Макет телефона: [`../index.html`](../index.html). Протокол: [docs/protocol_ru.md](../../../../docs/protocol_ru.md). URI импорта: [docs/share_ru.md](../../../../docs/share_ru.md). План: [PLAN](../../PLAN.md), фаза 4.

Живой GUI позже — Leanback (Java 17 Views, пульт). Без Compose. `connect` — только на ноде. Авто = GET.

---

## 1. Продукт

Приставка — хост в гостиной. YouTube, Play Store и остальные приложения идут через overlay, потому что у Android одна системная VPN. Обычный канал — Ethernet, Wi-Fi — запасной. Смена пути (`NetworkCallback` → `NotifyPathChange`) сохраняет адрес в сети loft.

Один профиль сразу: loft / SSTP / VLESS / Trojan. Именные подключения на диске, импорт/экспорт `.loft`, Подключить / Отключить, удержание системными тумблерами «VPN всегда включён», раздельная маршрутизация как **маршрут по умолчанию + обход LAN**. Редактор списков CIDR остаётся на телефоне.

Flavor `tv` в этом дереве. `LEANBACK_LAUNCHER`, баннер 320×180, тачскрин не обязателен, Leanback обязателен. Отдельный `applicationId`: `app.loft.android.tv` — телефон и приставка уживаются на одном аккаунте Google.

В v1 камеры на телевизоре нет. Импорт: QR **на экране** (телефон сканирует телевизор), файл `.loft` с флешки или из Загрузок, ссылка с пульта.

VIDAA / Tizen / webOS / Roku вне рамок.

## 2. Экраны

Нижней навигации, FAB и свайпов нет. Слева рельс (Дом / Подключения / Настройки), справа содержимое. Фокус по умолчанию — главное действие. Системный Назад всегда возвращает на шаг.

| Экран | Что |
|-------|-----|
| Дом | Марка, `loft`, статус (лампа + имя профиля + аптайм). Большая **Подключить** / **Отключить**. Выкл: справа карточка профиля (имя, `тип · фронт`, хост). В сети: overlay IP, внешний IP, чип Ethernet/Wi-Fi, ↓ / ↑ двумя крупными числами — графика скорости нет, с дивана его не прочитать. Подключение: **Отмена**, лампа в ожидании. Пустая приставка: три плитки добавления вместо Подключить. |
| Подключения | Одна горизонтальная лента Leanback. Карточка: имя, `loft · get`, хост. У живого — кромка лампы. Последняя карточка — **+**. OK на карточке делает её активной и возвращает на Дом. Вниз от ленты: Править · Поделиться QR · Удалить. |
| Добавить | Три плитки одного размера: **QR на телевизоре** · **С флешки или из Загрузок** · **Набрать ссылку**. |
| Связка | На экране крупный QR и код из шести знаков (`K7M2P4`). Текст: на телефоне loft → На телевизор → навести камеру (или ввести код). Телефон отдаёт YAML короткому слушателю в LAN. Назад гасит слушателя. |
| Поделиться QR | Тот же хром, что у связки, в QR — `loft://` выбранного профиля. Телефон забирает ключ с экрана. |
| Файл | Пикер Leanback по USB OTG и «Загрузки». `.loft`, `loft://`, YAML. Подтверждение: имя, тип · транспорт, хост; секрет скрыт. |
| Набор | Клавиатура Leanback. Поле `loft://` или YAML. **Добавить**. |
| Правка | Намеренно короткая. Имя, чипы способа **Авто · GET · WS · H2 · QUIC · H3 · L3**, Сохранить. Полные формы loft / SSTP / VLESS / Trojan — на телефоне. Пульт — не редактор YAML. |
| Настройки | Группы **Общие / Маршрут / Подключение**. Общие: язык, расширенный журнал. Маршрут: маршрут по умолчанию, обход LAN, **Без VPN — без интернета** ссылкой **Открыть настройки VPN** (системные «VPN всегда включён» и «Блокировать подключения без VPN»). Подключение: подключаться при запуске, переподключаться при обрыве. Внизу: Журнал · О программе. Редактора списков CIDR нет. |
| Журнал | Последние строки, ключ сокращён. Очистить — с подтверждением. |
| О программе | Марка, версия, loft/1.0 · SSTP · VLESS · Trojan, абзац, Made with love by A³. |
| Запрос | Системный **Запрос подключения** Android TV. Один раз. Дальше Подключить не спрашивает. |
| Системный VPN | Настройки → Сеть и интернет → VPN. Макет показывает loft в *их* списке. |
| Баннер | 320×180 для ряда Google TV / Play: тёмная бумага, марка L, слово `loft`, лампа горит, пока сессия жива. |

## 3. Пульт

| Клавиша | Действие |
|---------|----------|
| ← → | Рельс ↔ панель; вдоль ленты карточек. |
| ↑ ↓ | Иконки рельса; строки настроек; ряд действий под Подключениями. |
| OK | Фокус. На Доме это Подключить / Отключить. |
| Назад | Шаг назад. Связка / QR / набор / файл / правка закрываются. С Дома — выход Leanback. |

Фокус: кольцо лампы 3 px, отступ 4 px, карточка 1.06. Минимальное попадание 48 dp. Поля зрения 48 dp от края. Заголовок ~34 sp, текст ~20 sp, подсказка ~16 sp на 1080p.

В макете на ноутбуке стрелки, Enter и Escape — эта таблица.

## 4. Импорт без камеры

| Путь | Когда |
|------|-------|
| QR на телевизоре | Телефон и приставка в одной LAN. Предпочтительный. |
| Код из шести знаков | Та же связка, если на телефоне тоже нет камеры. |
| Флешка / Загрузки | Носитель или файл, который уже лежит на приставке. |
| Набор `loft://` | Запасной. IME Leanback медленный; поле принимает вставку с Bluetooth-клавиатуры. |

Сканер на телефоне уже есть. На TV всё наоборот: **экран** и есть QR.

Hairpin, dual-stack, `protect(fd)`, FrontIP `excludeRoute` — движок телефона. Этот макет их не перерисовывает.

## 5. Визуал

Те же токены, что на телефоне: Ink `#1A1714`, Lamp `#E8B84A`, Paper `#E8DFD2`, Avenir Next. Хром TV — тёмная бумага loft до краёв. Системные диалоги (Запрос подключения, Настройки VPN) оставляют хром OEM, чтобы была видна граница продукта.

В сети = окно лампы горит. Выкл = лампа погашена, каменная L. Без сиреневого Material You. Без нижней панели телефона, без FAB, без плитки быстрых настроек (на Android TV её нет).

Общие кнопки — из `clients/macOS/lang/*.lang`. Свои строки TV: три плитки добавления, связка, флешка, подсказки пульта. Регистр VPN каждого языка.

| id | EN | RU |

| disconnect | Disconnect | Отключить |

| add_usb | From USB or Downloads | С флешки или из Загрузок |

| pair_hint | Open loft on the phone → Send to TV | На телефоне: loft → На телевизор |
