# План · loft на Android

[English](PLAN.md) · **Русский**

ПО 1.0.0. Протокол 1.0. План версии не повышает.

## Цель

Клиент loft / SSTP / VLESS на телефоне, затем на **Android TV / Google TV**, как системный VPN. Пользователь импортирует ключ (`loft://`, `sstp://`, `vless://`, `.loft`), нажимает Подключить — трафик устройства идёт в сессию. На loft смена Wi-Fi / LTE / Ethernet сохраняет IP оверлея (билет `0x03`).

Google TV — оболочка поверх Android TV. Один flavor `tv`, один AAR, один `VpnService`.

## Вне рамок

- Kotlin / Compose. Адаптер — Java 17 Views (телефон) и Leanback (ТВ). gomobile уже отдаёт Java.
- Запуск `loft-front`. `LoftVpnService` *и есть* сессия.
- SOCKS5 как вход, которым пользуются чужие приложения. Стриминг в локальный прокси не ходит; вход продукта — `VpnService`.
- Несколько VpnService сразу (Android держит один).
- IKEv2 / WireGuard внутри этого приложения. SSTP — Go в процессе на той же службе.
- **VIDAA, Tizen, webOS, Roku.** TUN нет. Эти телевизоры — через Keenetic (или HDMI-стик с этим клиентом).
- Fire TV как отдельный листинг в первой выкладке ТВ (тот же APK можно sideload).
- Страница Play Store в первой выкладке сборки (достаточно sideload).
- Dist / APK в GitHub Release `v*` до следующего тега.

## Фазы

### 0. Каталог — это дерево

Документы, HTML-макет ([design/](design/)). Тонкий хост Java уже вставляет YAML.

### 1. Тонкий VpnService

`gomobile bind` [`clients/mobile`](../mobile/) (`make -C ../mobile android` → `engine.aar`). `LoftVpnService` качает tun fd, `protect(fd)`, маршруты/DNS из Snapshot. Написано. Для bind на машине нужен NDK.

### 2. GUI телефона

Заменить экран вставки YAML макетом: дом (лампа, Подключить/Отключить), подключения, сканер, правка, настройки, онбординг. Java Views. Простой вид по умолчанию.

### 3. Профили и политика машины

Профили на диске, указатель активного, ключ `lt_…` в Android Keystore. Импорт/экспорт `.loft`.

- Один активный профиль (одна строка VPN).
- Удержание: переход в **VPN всегда включён** и **Блокировать без VPN**. В копирайте *маршрут* / *прямой Интернет*.
- Сплит: списки протокола → маршруты (`via` / `direct` / `drop`). `excludeRoute` на IP фронтов (API 33+); `protect(fd)` на любой OS.
- Сканер: камера QR + SAF + Photo Picker. Детектор: `loft://`, `sstp://`, `vless://`, YAML / `.loft` (одно или несколько подключений). Intent `loft`. Подтвердить, затем сохранить. Список: свайп Править/Удалить, долгое нажатие, экспорт когда выбрано. Подпись тип · транспорт · хост.
- Шторка, пока сессия жива. Плитка быстрых настроек.

### 4. Android TV / Google TV

Product flavor `tv` в этом дереве (Leanback, D-pad, баннер, `LEANBACK_LAUNCHER`). Тот же `engine.aar` и `LoftVpnService`.

- 10-foot дом / список / настройки. Телефонные вёрстки остаются в phone flavor.
- Камеры ТВ нет: обратный QR (телефон сканирует ТВ), `.loft` из хранилища, вставка с клавиатуры пульта.
- Play на ТВ показывает только leanback; телефонный APK там не всплывёт, пока flavor не помечен.
- RSS мерить на коробке 2 ГиБ, прежде чем обещать дешёвые стики. Сначала Shield / Google TV Streamer.

### 5. Пакет

Подписанный APK / AAB. GitHub Actions позже; не в первом теге. Sideload на Pixel и Shield достаточно, чтобы гонять самим.

## Порядок работ в дереве Go

1. [`clients/mobile`](../mobile/) — уже движок телефона и ТВ. Без флагов CLI.
2. Смена пути: `ConnectivityManager.NetworkCallback` → `NotifyPathChange`. Билет `0x03` на loft.
3. Возможности протокола не добавлять. `loft-front` оставить для macOS.

## Риски

| Риск | Смягчение |
|------|-----------|
| RSS Go на ТВ-коробке 1–2 ГиБ | Замер на Shield. Убрать лишние транспорты из bind при необходимости. |
| Петля | `protect(fd)` плюс `excludeRoute` (API 33+). |
| OEM без листа согласия VPN | Документировать; полный туннель может не подняться. Это не баг loft. |
| Поиск Play TV | Категория leanback только на flavor `tv`. |
| QR с ключом участника | Экран подтверждения; URI в журнал не писать. У ТВ камеры нет. |

## Готово когда

**Телефон.** Участник на API 26+ импортирует `.loft` или URI `loft://`, нажимает Подключить, видит лампу, Chrome идёт с IP оверлея. Wi-Fi → LTE этот IP сохраняет.

**ТВ.** Та же сессия на Android TV / Google TV с пульта: импорт без камеры ТВ, Подключить, YouTube идёт с IP оверлея. Ethernet → Wi-Fi этот IP сохраняет.
