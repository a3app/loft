# loft · панель Keenetic

[English](DESIGN.md) · **Русский** · [中文](DESIGN_zh.md)

Интерактивный макет: [`index.html`](index.html). Фирменный стиль: [`brand/`](../../../docs/brand/). Интеграция: [docs/keenetic_ru.md](../../../docs/keenetic_ru.md).

Панель — это небольшой сайт в локальной сети. Приоритеты подключений, политики и DNS-маршруты остаются за Keenetic. Этот интерфейс только поднимает сессию loft и записывает YAML.

---

## 1. Продукт

Одно именованное подключение. Один OpkgTun. Несколько фронтов внутри loft (`select: auto`). VLESS появится позже, на том же интерфейсе.

Оператор:

1. Входит в веб-админку Keenetic.
2. Открывает `http://<lan-ip>:8090/` (cookie ещё действует, иначе — штатный вход и возврат обратно).
3. Вставляет ключ участника и URL ноды, выбирает фронт, сохраняет, запускает.
4. В Keenetic открывает **Сетевые правила → Приоритеты подключений** и перетаскивает **Loft**.

Второго пароля нет. Формы для SSTP нет.

## 2. Экраны

| Экран | Что |
|-------|-----|
| Вход | Проверка сессии Keenetic. 401 → штатный `/` с `return=`. |
| Статус | Лампа, IP / шлюз / MTU оверлея, активный фронт, счётчики байтов, Старт/Стоп. Ссылка: «Открыть приоритеты Keenetic». |
| Подключение | Имя, ключ `lt_…` (после сохранения скрыт), URL, тип, путь, опционально профиль CDN и отпечаток uTLS. |
| Фронты | Галочки get / ws / h2 / quic / h3 / l3. Порядок в списке = порядок попыток. После рукопожатия список пересекается со Status `caps`. |
| VLESS | Выключенный блок. Текст: «Тот же туннель, позже.» |
| Журнал | Последние 80 строк лога демона. Ключи в журнал не попадают. |

Простой вид (по умолчанию): Статус + Подключение. Фронты, журнал и VLESS спрятаны под «Дополнительно».

## 3. Системный интерфейс Keenetic

Штатный интерфейс на `:80` не перекрашиваем. Макет показывает, как **Loft** выглядит у *них* в «Других подключениях» и приоритетах: строка, похожая на WAN, с описанием Loft; тумблер в ней — это NDM `up`, а не наш Старт. Наш Старт запускает процесс, после чего `ndmc` выставляет `up`.

Позже, по желанию: карточка на дашборде, которая только ведёт на `:8090`. Это версионируемая вставка, но ни в коем случае не форма настроек.

## 4. Визуал

Те же токены loft, что на macOS: Ink `#1A1714`, Lamp `#E8B84A`, Paper `#E8DFD2`, Avenir Next. Рамка Keenetic в макете светлая, как их админка, чтобы оператор видел оба мира.

Шрифт: заголовки — Demi, текст — Regular, ключи — SF Mono. Есть подключение — окно лампы горит. Нет подключения — лампа погашена, буква L цвета камня.

Адрес в подвале: `http://192.168.1.1:8090/`, доступен только из LAN.
