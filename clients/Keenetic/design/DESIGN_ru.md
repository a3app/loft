# loft · панель Keenetic

[English](DESIGN.md) · **Русский** · [中文](DESIGN_zh.md)

Интерактивный макет: [`index.html`](index.html). Марка: [`brand/`](../../../docs/brand/). Интеграция: [docs/keenetic_ru.md](../../../docs/keenetic_ru.md).

Панель — маленький LAN-сайт. Приоритеты, политики и DNS-маршруты остаются в Keenetic. Этот UI только поднимает сессию loft и пишет YAML.

---

## 1. Продукт

Одно именованное подключение. Один OpkgTun. Несколько фронтов внутри loft (`select: auto`). VLESS — позже, тот же интерфейс.

Оператор:

1. Входит в веб-админку Keenetic.
2. Открывает `http://<lan-ip>:8090/` (cookie уже живая, или стоковый логин и возврат).
3. Вставляет ключ участника и URL ноды, выбирает фронт, сохраняет, запускает.
4. В Keenetic: **Сетевые правила → Приоритеты подключений** — перетащить **Loft**.

Второго пароля нет. Формы SSTP нет.

## 2. Экраны

| Экран | Что |
|-------|-----|
| Ворота | Проверка сессии Keenetic. 401 → стоковый `/` с `return=`. |
| Статус | Лампа, IP / шлюз / MTU оверлея, живой фронт, байты, Старт/Стоп. Ссылка: «Открыть приоритеты Keenetic». |
| Подключение | Имя, ключ `lt_…` (после сохранения скрыт), URL, тип, путь, опционально профиль CDN и отпечаток uTLS. |
| Фронты | Галочки get / ws / h2 / quic / h3 / l3. Порядок = порядок попыток. После рукопожатия — пересечение со Status `caps`. |
| VLESS | Выключенный блок. Текст: «Тот же туннель, позже.» |
| Журнал | Последние 80 строк демона. Ключа нет. |

Простой вид (по умолчанию): Статус + Подключение. Фронты, журнал, VLESS — за «Дополнительно».

## 3. Хром Keenetic

Стоковый `:80` не перекрашиваем. Макет показывает, как **Loft** выглядит у *них* в «Другие подключения» / приоритетах: строка как WAN, описание Loft, тумблер — NDM `up`, не наш Старт. Наш Старт поднимает процесс, затем `ndmc` ставит `up`.

Позже по желанию: карточка на дашборде — только ссылка на `:8090`. Инжект с версией, никогда не форма настроек.

## 4. Визуал

Те же токены loft, что на macOS: Ink `#1A1714`, Lamp `#E8B84A`, Paper `#E8DFD2`, Avenir Next. Рамка Keenetic в макете светлая (их админка), чтобы было видно оба мира.

Шрифт: заголовки Demi, текст Regular, ключи SF Mono. В сети — окно лампы горит. Выкл — лампа погашена, L камня.

Адрес в подвале: `http://192.168.1.1:8090/` — только LAN.
