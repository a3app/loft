# loft-wintun-check

[English](README.md) · **Русский** · [中文](README_zh.md)

Проверяет, работает ли драйвер Wintun на Windows 7 SP1 (x86 и x64), до того как строить на нём Windows-клиент. См. [`../design/DESIGN_ru.md`](../design/DESIGN_ru.md) §10.

Программа ставит Wintun 0.14.1, создаёт адаптер `LoftTest` с адресом `10.255.0.1/24`, пингует `10.255.0.2` и сама отвечает на ping через адаптер — так проверяются оба направления. В конце удаляет адаптер и драйвер. Всё пишется в `loft-wintun-check.txt` рядом с exe, включая строки журнала самого Wintun. Вывод на экран — по-русски.

## Сборка

```
make GO=~/sdk/go1.20.14/bin/go zip
make GO=/path/to/go-win7/bin/go GOROOT=/path/to/go-win7 zip
```

Модуль отдельный (`go 1.20`), чтобы его собирали и официальный Go 1.20.14, и патченный Go для Windows 7. `wintun.dll` в git нет: `make` скачивает `wintun-0.14.1.zip` с wintun.net и проверяет SHA-256.

## Запуск

1. Распаковать `x86` (32-битная Windows) или `x64` (64-битная); exe и `wintun.dll` лежат рядом.
2. Запустить `loft-wintun-check.exe` и согласиться на запрос администратора.
3. Дождаться строки ИТОГ и нажать Enter. Прислать `loft-wintun-check.txt`.

Если адаптер не создаётся, проверьте обновление KB4474419 (подпись кода SHA-2). Без него Windows 7 не принимает подпись драйвера.
