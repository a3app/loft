# Loft · клиент ОС Аврора

[English](DESIGN.md) · **Русский** · [中文](DESIGN_zh.md)

Приложение и строка оверлея ConnMan. Марка, палитра и Avenir Next: [`brand/`](../../../docs/brand/). Интерактивный макет: [`index.html`](index.html). Протокол: [docs/protocol_ru.md](../../../docs/protocol_ru.md). URI импорта: [docs/share_ru.md](../../../docs/share_ru.md).

Контейнер QML в [`../qml/`](../qml/). Живая сессия — `loft-front`, не gomobile. Тонкий хост уже вставляет YAML; этот макет — GUI, который заменит экран вставки.

Приложение — **Loft**. Протокол — **loft** / **LOFT**.

---

## 1. Продукт

Локальный вход — системная строка оверлея (ConnMan). Один профиль сразу: loft (`lt_…`, пароля нет), SSTP (логин + пароль), VLESS (`vless://`) или Trojan (`trojan://`).

v1: именные подключения на диске, импорт/экспорт `.loft`, Подключить/Отключить, удержание, сплит по зонам. `select: auto` внутри YAML loft. Туннель один.

Файл `.loft` держит **одно или несколько подключений**. Типы смешиваются: `loft`, `sstp`, `vless`, `trojan`. Подпись в списке — **тип · транспорт · хост** (`loft · get · cdn.example.com`). Адрес loft — строка `loft://`. Спецификация: [docs/share_ru.md](../../../docs/share_ru.md).

Шаринга: сканер QR или файл/картинка с `loft://`, `sstp://`, `vless://`, `trojan://` или `.loft`.

Настройки Авроры показывают ту же строку, которую поднимает плагин. Приложение не подменяет Настройки.

Язык адаптера — **Qt 5 / QML Silica**. Макет — HTML; живой GUI позже страницами Silica (без Widgets).

| Сканер | Камера QR. Из файла. Вставка `loft://` / `sstp://` / `vless://` / `trojan://`. Подтверждение: имя, тип, транспорт, хост; секрет скрыт. |

VLESS Ссылка — строка `vless://`; Вручную — UUID, хост, порт, TLS·REALITY, TCP·XHTTP, имя хоста TLS, отпечаток и поля режима. Проверка сертификата. Оба пишут `vless://`. SSTP: пользователь, пароль, сервер, имя хоста TLS, проверка сертификата, PAP/CHAP. Trojan: пароль, сервер `trojan://`, имя хоста TLS, проверка сертификата. QR выбранного исходящего. Экспорт `.loft` этого подключения. |

| Обложка | Лампа + Подключить/Отключить. С домашнего экрана. |
| Журнал | Последние строки loft-front. Без ключа. За «Расширенные». |

## 3. Хром Авроры

Не перекрашивать Настройки → VPN. Макет показывает, как **Loft** выглядит *у них* в списке: статус Подключено, тип Loft, тумблер — системная строка, не второй тумблер в нашем приложении.

Подключить пишет YAML и просит ConnMan активировать соединение loft. Если плагина нет, приложение стартует `loft-front` с SOCKS на loopback.

Камера — штатный лист при первом Сканере. Файлы: разрешение Документы.

Схема `loft`: тап по `loft://…` предлагает импорт.

Удержание — default ConnMan остаётся занятым. Копирайт: *маршрут* / *прямой интернет*.

Зоны: Через Loft / Мимо Loft. Направление живёт на зоне.

## 4. Вид

Те же токены loft, что на iOS, Android и macOS: Ink `#1A1714`, Lamp `#E8B84A`, Paper `#E8DFD2`, Avenir Next. Хром телефона в макете — loft (тёмная бумага). Шторка и обложка — Аврора; Material и iOS nav не копируем.
