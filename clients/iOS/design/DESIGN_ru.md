# loft · клиент iOS

[English](DESIGN.md) · **Русский**

Приложение и Packet Tunnel. Марка, палитра и Avenir Next: [`brand/`](../../../brand/). Интерактивный макет: [`index.html`](index.html). Протокол: [docs/protocol_ru.md](../../../docs/protocol_ru.md). URI импорта: [docs/share_ru.md](../../../docs/share_ru.md).

Контейнер SwiftUI позже в [`../App/`](../App/). Живая сессия — Go внутри Network Extension, не `loft-front`.

Макет следует **живому GUI macOS** (`clients/macOS`, `L10n.swift`, статус / список / правка / настройки / онбординг / журнал / о программе) на телефоне. Тексты, поля и IA — как у того клиента. iOS держит один Packet Tunnel, сканер камеры, свайп и долгое нажатие в списке, системную строку VPN. Не появляется SOCKS-вход, Dock, login item и несколько туннелей сразу.

---

## 1. Продукт

Локальный вход — системный VPN (Packet Tunnel). Один профиль сразу: loft (`lt_…`, пароля нет), SSTP (логин + пароль) или VLESS (`vless://`).

v1: именные подключения на диске, импорт/экспорт `.loft`, Открыть лофт / Отключить, удержание, сплит по спискам протокола. `select: auto` внутри YAML loft. Туннель один.

Файл `.loft` держит **одно или несколько подключений**. Типы смешиваются: `loft`, `sstp`, `vless`. Адрес loft в UI — строка `loft://`. Спецификация: [docs/share_ru.md](../../../docs/share_ru.md).

Шаринга: сканер QR или картинка/файл с `loft://`, `sstp://`, `vless://` или `.loft`.

Настройки iOS показывают ту же строку VPN, которую поднимает приложение. Приложение не подменяет Настройки.

Apple TV (tvOS 17+) — тот же Packet Tunnel после GUI iPhone. [План](../PLAN_ru.md) фаза 6. Этот макет — телефон.

Те же комнаты, что окна macOS, в одну колонку под большой палец.

|-------|-----|
| Дом | Окно статуса. Марка, `loft`, пилюля статуса (тап → список), большая Открыть лофт / Отключить. Карточки **OVERLAY / ФРОНТ / ТУННЕЛЬ** и искра, если упрощенный интерфейс выкл. Подвал **Журнал \| Сбросить маршруты \| Настройки**. Подключение — этот же экран: пилюля «Не подключено», действие «Подключение…», искра «рукопожатие». |

Активное одно.» Строка: компактное Подключить/Отключить, имя, подпись **хост**, сбоку **активно** или тип (`get` / `sstp` / `vless`), призрак Править. **Свайп слева** — править, **справа** — удалить. **Долгое нажатие** — меню: Править / Экспорт `.loft` (только выбранное) / Удалить. | Правка | Заголовок Подключение, **QR** в шапке. Имя. Капсула **Тип VPN** loft / SSTP / VLESS / Trojan. Вкладки **Основные / Расширенные**. Основные loft — секретный адрес `loft://` с Показать/Скрыть. Поля SOCKS нет. Интерфейс туннеля = Packet Tunnel (всегда вкл.: другого входа нет). | Онбординг | Два шага, как на macOS. **1 Ключ доступа** (`lt_…`) → Продолжить, или импорт файла/QR. **2 Адрес**: URL, как подключаться GET/WS/H2/QUIC/H3, путь → Открыть лофт. Затем стоковый лист разрешения VPN iOS, один раз. |
| Настройки | Три вкладки **Общие / Маршрут / Клиент**. В шапке Сбросить маршруты. Ссылки **По умолчанию \| Журнал \| О программе**. Подмножество iOS: язык, упрощенный интерфейс, единицы скорости, расширенный журнал; маршрут по умолчанию, удержание, сплит (без failover); автоподключение, реконнект, внешний IP. Без Dock, login item, нескольких исходящих, SOCKS. |
| Журнал | Строки фронта и сессии. Ключ сокращается. Скопировать / Очистить / Назад. |
| О программе | Марка, loft, `1.0.9`, протоколы loft/1.0 · SSTP · VLESS · Trojan, абзац, «Made with love by A³». |
| Сканер | Камера QR. Из файла / Из Фото. Вставка `loft://` / `sstp://` / `vless://`. |
| QR ссылки | `loft://` одного фронта. Несколько фронтов или несколько подключений → `.loft`. Предупреждение, что в файле ключ. |
| Настройки iOS → VPN | Стоковый список. loft Connected, тип loft. Тумблер — системный туннель. |

Хром только macOS, которого в макете нет: поповер строки меню, карточка и порт SOCKS5, значок Dock, login item, несколько исходящих сразу, пластина drag-and-drop.

## 3. Хром iOS

Не перекрашивать Настройки → VPN. Макет показывает, как **loft** выглядит в *их* списке VPN: статус Connected, тип loft, тумблер — системный туннель, не второй выключатель в нашем приложении.

Открыть лофт вызывает `NETunnelProviderManager`. Если пользователь выключил loft в Настройках, приложение показывает выкл.

Разрешение VPN — стоковый лист один раз. Дальше Открыть лофт не спрашивает.

Разрешение камеры — стоковый лист при первом Сканировать (`NSCameraUsageDescription`). Фото — `PHPicker` (без полного доступа к медиатеке). Файлы: картинки, текст, YAML, `.loft`.

Схема URL `loft`: тап по `loft://…` предлагает импорт.

### Жесты списка

Словарь Почты / Файлов на телефоне. Список macOS держит призрак Править на строке; iOS добавляет свайп и долгое нажатие — указателя нет.

| Жест | Действие |
|------|----------|
| Тап | Выбрать. Если жило другое подключение — отключить его и подключить это. |
| Компактное Подключить / Отключить | Та же кнопка, что в списке macOS (`Подключить` / `Отключить`). |
| Свайп влево | Удалить, с листом подтверждения. |
| Свайп вправо | Править. |
| Долгое нажатие | Меню: Править; Экспорт `.loft`, если строка выбрана; Удалить. |
| Экспорт на выбранной строке | Лист: это подключение как `Name.loft`; QR `loft://` живого фронта; все подключения как `Family.loft`. Лист повторяет предупреждение про ключ. |

## 4. Визуал

Те же токены, что на macOS: Ink `#1A1714`, Lamp `#E8B84A`, Paper `#E8DFD2`, Avenir Next. Хром телефона в макете — loft (тёмная бумага), не серые группы iOS.

Шрифт: заголовки Demi, текст Regular, ключи SF Mono. В сети = окно лампы горит. Выкл = лампа погашена, каменная L.

Safe area: статус-бар + индикатор домой. Одна колонка. Большая Открыть лофт / Отключить на доме — под большой палец. Три пилюли подвала сидят над индикатором.

Сканер: тёмный видоискатель, угловые скобки цвета лампы, два действия под кадром (Из файла / Из Фото).

Тип VPN — **капсула** (заливка лампы на выбранном), вкладки Основные/Расширенные и Настройки — тот же сегмент, что на macOS.

## 6. Соответствие GUI macOS

| macOS | макет iOS |
|-------|-----------|
| Окно статуса | Дом |
