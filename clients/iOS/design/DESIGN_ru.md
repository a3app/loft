# loft · клиент iOS

[English](DESIGN.md) · **Русский** · [中文](DESIGN_zh.md)

Приложение для телефона и Packet Tunnel. Знак, палитра и Avenir Next: [`brand/`](../../../docs/brand/). Интерактивный макет: [`index.html`](index.html); у каждого состояния своя ссылка, например `index.html#edit-sstp`, `#settings-route`, `#home-off` (адрес меняется при переходах). Протокол: [docs/protocol_ru.md](../../../docs/protocol_ru.md). URI импорта: [docs/share_ru.md](../../../docs/share_ru.md).

Контейнер SwiftUI лежит в [`../App/`](../App/). Home — это `HomeView` с Canvas `#Preview` (`Home · off` / `on` / `simple`; плюс connecting, ru, zh). Настройки — `SettingsView` (`Settings` / `Settings · ru` / `About`): Общие / Маршрут / Подключение; выбор языка применяется сразу через `LoftPrefs`. Рабочую сессию ведёт Go внутри Network Extension, а не `loft-front`. YAML-хост `ContentView` остаётся, пока не появятся профили.

Макет переносит на телефон **рабочий GUI macOS** (`clients/macOS`, `L10n.swift`, статус / список / правка / настройки / онбординг / журнал / о программе). Тексты, поля и IA совпадают с этим клиентом. На iOS остаются один Packet Tunnel, сканер камеры, свайп и долгое нажатие в списке, системная строка VPN. SOCKS-входа, Dock, login item и нескольких одновременных туннелей здесь нет.

## 1. Продукт

Локальным входом служит системный VPN (Packet Tunnel). Одновременно активен один профиль: loft (`lt_…`, пароля нет), SSTP (логин + пароль) или VLESS (`vless://`).

v1: именованные подключения на диске, импорт/экспорт `.loft`, Подключить / Отключить, удержание, раздельная маршрутизация по спискам протокола. `select: auto` внутри YAML loft. Одновременно работает один туннель.

Файл `.loft` содержит **одно или несколько подключений**. Типы можно смешивать: `loft`, `sstp`, `vless`. В интерфейсе адрес loft записывается строкой `loft://`. Спецификация: [docs/share_ru.md](../../../docs/share_ru.md).

Обмен: отсканировать QR-код или загрузить картинку/файл с `loft://`, `sstp://`, `vless://` или `.loft`.

Настройки iOS показывают ту же строку VPN, которую поднимает приложение. Приложение не подменяет Настройки.

Apple TV (tvOS 17+) получит тот же Packet Tunnel после GUI для iPhone: [план](../PLAN.md), фаза 6. Этот макет — для телефона.

### Раздельная маршрутизация

Модель macOS (DESIGN macOS §5): **зона** идёт через loft или в обход, **сервис** (имя + CIDR) только принадлежит зоне, **исключение** — CIDR, который не входит в зону и сохраняется при обновлении списка. Встроенные зоны — Local (в обход, LAN) и Global (через, `global.bat`); свои создаются в редакторе. На iOS «через loft» означает `includedRoutes` Packet Tunnel, «в обход» — `excludedRoutes`; пока туннель выключен, всё и так идёт напрямую. Запоминания прямого хопа, как на macOS, нет.

Вход: Настройки → Маршрут → тумблер и золотая **Списки**. Экраны открываются внутри вкладки Настройки, вверху **‹ Настройки** / **‹ Назад**.

| Экран | Что |
|-------|-----|
| Списки | Заголовок и тот же тумблер, подпись (через — в туннель, в обход — напрямую). **Зона** + **Зоны** → редактор. Вкладки-капсулы зон с числом сервисов. Тихая строка `Global · Через loft`. Поиск. Строки: имя, первые CIDR, число сетей, источник (список / свои); тап — правка. Строка **Исключения · N ›**. **+ Добавить**. Внизу **Импорт · Экспорт · Репозиторий**. |
| Сеть | Запись Маршрут / Исключение, сеть или адрес (в правке — по строке на CIDR), сервис, зона. Добавить / Сохранить. |
| Зоны | Строки: имя, число сетей · файл списка, направление, «Встроенная». **+ Добавить зону**. |
| Зона | Имя (у встроенной закрыто), направление Через loft / В обход loft, адрес списка + **Списки**, автообновление, Сохранить; у своей — Удалить зону (сервисы → Global). Новая зона — те же поля. |
| Репозиторий | Адрес списка открытой зоны + **Списки**, автообновление, последнее обновление, Обновить сейчас. |
| Каталог | Списки loft-routes: Мир, Россия, Китай, Иран, Казахстан, Беларусь; текущий подсвечен. Тап ставит адрес и возвращает назад. |
| Импорт | Из файла (Файлы iOS), распознанный формат и число строк, зона, Добавить. |
| Экспорт | Все зоны в одном файле loft-routes (зона — в `REM zone:`, имя сервиса — в комментарии), образец, Сохранить (лист «Поделиться»). |

**Очистка.** Удаление срабатывает сразу. Внизу на 5 с появляется snackbar «Удалено: YouTube · **Отменить**», он возвращает всё как было. Отдельного диалога нет, кроме очистки зоны и исключений.

- **Свайп влево** по строке сервиса открывает красное **Удалить**.
- **Долгое нажатие** на строку включает выбор. Шапку заменяет панель: **✕**, «Выбрано: N», **Все** (все сервисы открытой зоны, повторное нажатие снимает выбор), **Удалить**. Строки получают кружок-отметку, тап по строке отмечает её.
- На экране **Сеть** у существующей записи внизу **Удалить сервис** (у исключения — **Удалить исключение**). Экран закрывается, появляется snackbar.
- **⋯** в навбаре Списков: **Выбрать** (тот же режим выбора) и **Очистить зону**. Диалог «Очистить Global?»: **Только свои (N)** и **Всё, включая список (M)**. «Всё» отвязывает список зоны: адрес и автообновление отключаются, иначе сервисы вернутся при обновлении. Исключения остаются. Если в зоне нет сервисов из списка, в диалоге одна строка **Удалить все**.

Сервис из списка (источник «список») при удалении не пропадает бесследно: его сети уходят в исключения зоны, иначе следующее обновление вернёт их обратно (правило macOS §5). Snackbar так и пишет: «… · сети списка — в исключениях». Свои сервисы удаляются насовсем.

**Исключения** живут на своём экране, а не в общем списке. Под списком сервисов идёт строка **Исключения · N ›**. Экран «Global · Исключения» (вверху **‹ Назад**): подпись «Эти сети не ставятся и не возвращаются при обновлении списка», строки CIDR (моноширинный) с именем сервиса справа, тап — правка на экране Сеть. **Свайп влево** открывает **Вернуть**: исключение удаляется, и сеть придёт с ближайшим обновлением списка. **+ Добавить** открывает Сеть с выбранным «Исключение». Внизу **Очистить исключения** с диалогом.

## 3. Системный интерфейс iOS

Не перекрашивать Настройки → VPN. Макет показывает, как **loft** выглядит в *их* списке VPN: статус Connected, тип loft, тумблер управляет системным туннелем, а не служит вторым выключателем в нашем приложении.

Подключить вызывает `NETunnelProviderManager`. Если пользователь выключил loft в Настройках, приложение показывает состояние «выкл».

Разрешение на VPN запрашивается системным листом один раз. Дальше Подключить ничего не спрашивает.

Разрешение на камеру запрашивается системным листом при первом сканировании (`NSCameraUsageDescription`). Фото выбираются через `PHPicker` (без полного доступа к медиатеке). Диалог выбора файлов принимает картинки, текст, YAML, `.loft`.

Схема URL `loft`: тап по `loft://…` предлагает импорт.

### Жесты списка

Жесты те же, что в Почте и Файлах на телефоне. В списке macOS на строке есть «призрачная» кнопка Править; iOS добавляет свайп и долгое нажатие, потому что указателя нет.

| Жест | Действие |
|------|----------|
| Тап | Открыть подключение (Правка). Подключает компактная кнопка Подключить; если было активно другое подключение, оно сначала отключается. |
| Компактное Подключить / Отключить | Та же кнопка, что в списке macOS (`Подключить` / `Отключить`). |
| Свайп влево | Удалить, с листом подтверждения. |
| Свайп вправо | Править. |
| Долгое нажатие | Меню: Править; Экспорт `.loft`, если строка выбрана; Удалить. |
| Экспорт на выбранной строке | Лист: это подключение как `Name.loft`; QR `loft://` живого фронта; все подключения как `Family.loft`. Лист повторяет предупреждение про ключ. |

## 4. Визуал

Те же токены, что на macOS: Ink `#1A1714`, Lamp `#E8B84A`, Paper `#E8DFD2`, Avenir Next. Оформление телефона в макете — loft (тёмная бумага), не серые группы iOS.

Шрифт: заголовки Demi, текст Regular, ключи SF Mono. В сети = окно лампы горит. Выкл = лампа погашена, каменная L.

Safe area: статус-бар + индикатор домой. Одна колонка. Большая кнопка Подключить / Отключить на Доме — в зоне большого пальца. Панель вкладок **Дом · Подключения · Настройки** расположена над индикатором и видна на Доме, в Подключениях, в Настройках и на открытых из них экранах (Журнал, О программе). Правка, Сканер и QR — модальные экраны без неё; Онбординг — во весь экран.

Сканер: тёмный видоискатель, угловые скобки цвета лампы, два действия под кадром (Из файла / Из Фото).

Тип VPN — **капсула** (заливка лампы на выбранном), вкладки Основные/Дополнительно и Настройки — тот же сегмент, что на macOS.

## 5. Тексты

Общие строки — кнопки, настройки, маршруты — берутся из `clients/macOS/lang/*.lang` и звучат одинаково на macOS и iOS. Свои тексты у iOS только там, где нет аналога на macOS: карточки Дома и лист Подробности, **Подключаться по требованию** и **Доверенные сети Wi‑Fi**, стартовый экран, лист «+». Макет по умолчанию на русском (`?lang=en` или переключатель RU/EN). Действие на Доме, на стартовом экране и компактная кнопка в списке называются одинаково — **Подключить**; во время подключения — **Подключение…**. Ключ — **Ключ доступа**, не ключ участника. Формулировки — в привычном языке VPN от Apple и операторской маршрутизации, без калек вроде «включаться само».

| auto | Connect at Launch | Подключаться при запуске |
| reconnect | Reconnect on Disconnect | Переподключаться при обрыве |
| demand | Connect On Demand | Подключаться по требованию |
| trusted | Trusted Wi‑Fi | Доверенные сети Wi‑Fi |
| split | Split Routing | Раздельная маршрутизация |
| default_route | Default Route | Маршрут по умолчанию |
| blurb | On the outside, ordinary HTTPS. Inside, a network of its own. | Снаружи — обычный HTTPS. Внутри — своя сеть. |

Карточки статуса зависят от протокола (см. Дом); скорость показана рядом со столбиками искры в выбранных единицах. Адрес в сети loft и MTU — в листе Подробности по тапу.
