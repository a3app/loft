# loft · клиент iOS

[English](DESIGN.md) · **Русский** · [中文](DESIGN_zh.md)

Приложение и Packet Tunnel. Марка, палитра и Avenir Next: [`brand/`](../../../docs/brand/). Интерактивный макет: [`index.html`](index.html); у каждого состояния своя ссылка, например `index.html#edit-sstp`, `#settings-route`, `#home-off` (адрес меняется по мере кликов). Протокол: [docs/protocol_ru.md](../../../docs/protocol_ru.md). URI импорта: [docs/share_ru.md](../../../docs/share_ru.md).

Контейнер SwiftUI в [`../App/`](../App/). Home — `HomeView` с Canvas `#Preview` (`Home · off` / `on` / `simple`; плюс connecting, ru, zh). Настройки — `SettingsView` (`Settings` / `Settings · ru` / `About`): Общие / Маршрут / Подключение, язык сразу через `LoftPrefs`. Живая сессия — Go внутри Network Extension, не `loft-front`. YAML-хост `ContentView` остаётся до профилей.

Макет следует **живому GUI macOS** (`clients/macOS`, `L10n.swift`, статус / список / правка / настройки / онбординг / журнал / о программе) на телефоне. Тексты, поля и IA — как у того клиента. iOS держит один Packet Tunnel, сканер камеры, свайп и долгое нажатие в списке, системную строку VPN. Не появляется SOCKS-вход, Dock, login item и несколько туннелей сразу.

## 1. Продукт

Локальный вход — системный VPN (Packet Tunnel). Один профиль сразу: loft (`lt_…`, пароля нет), SSTP (логин + пароль) или VLESS (`vless://`).

v1: именные подключения на диске, импорт/экспорт `.loft`, Подключить / Отключить, удержание, раздельная маршрутизация по спискам протокола. `select: auto` внутри YAML loft. Туннель один.

Файл `.loft` держит **одно или несколько подключений**. Типы смешиваются: `loft`, `sstp`, `vless`. Адрес loft в UI — строка `loft://`. Спецификация: [docs/share_ru.md](../../../docs/share_ru.md).

Поделиться: сканер QR-кода или картинка/файл с `loft://`, `sstp://`, `vless://` или `.loft`.

Настройки iOS показывают ту же строку VPN, которую поднимает приложение. Приложение не подменяет Настройки.

Apple TV (tvOS 17+) — тот же Packet Tunnel после GUI iPhone. [План](../PLAN.md) фаза 6. Этот макет — телефон.

### Раздельная маршрутизация

Модель macOS (DESIGN macOS §5): **зона** идёт через loft или в обход, **сервис** (имя + CIDR) только принадлежит зоне, **исключение** — CIDR, который не входит в зону и сохраняется при обновлении списка. Встроенные зоны Local (в обход, LAN) и Global (через, `global.bat`), свои — из редактора. На iOS «через loft» — `includedRoutes` Packet Tunnel, «в обход» — `excludedRoutes`; пока туннель выключен, всё и так идёт напрямую. Снимка прямого хопа, как на macOS, нет.

Вход: Настройки → Маршрут → тумблер и золотая **Списки**. Экраны открываются внутри вкладки Настройки, вверху **‹ Настройки** / **‹ Назад**.

| Экран | Что |
|-------|-----|
| Списки | Заголовок и тот же тумблер, подпись (через — в туннель, в обход — напрямую). **Зона** + **Зоны** → редактор. Вкладки-капсулы зон с числом сервисов. Тихая строка `Global · Через loft`. Поиск. Строки: имя, первые CIDR, число сетей, источник (список / свои / исключ.); тап — правка. **+ Добавить**. Внизу **Импорт · Экспорт · Репозиторий**. |
| Сеть | Запись Маршрут / Исключение, сеть или адрес (в правке — по строке на CIDR), сервис, зона. Добавить / Сохранить. |
| Зоны | Строки: имя, число сетей · файл списка, направление, «Встроенная». **+ Добавить зону**. |
| Зона | Имя (у встроенной закрыто), направление Через loft / В обход loft, адрес списка + **Списки**, автообновление, Сохранить; у своей — Удалить зону (сервисы → Global). Новая зона — те же поля. |
| Репозиторий | Адрес списка открытой зоны + **Списки**, автообновление, последнее обновление, Обновить сейчас. |
| Каталог | Списки loft-routes: Мир, Россия, Китай, Иран, Казахстан, Беларусь; текущий подсвечен. Тап ставит адрес и возвращает назад. |
| Импорт | Из файла (Файлы iOS), распознанный формат и число строк, зона, Добавить. |
| Экспорт | Все зоны в одном файле loft-routes (зона — в `REM zone:`, имя сервиса — в комментарии), образец, Сохранить (лист «Поделиться»). |

## 3. Хром iOS

Не перекрашивать Настройки → VPN. Макет показывает, как **loft** выглядит в *их* списке VPN: статус Connected, тип loft, тумблер — системный туннель, не второй выключатель в нашем приложении.

Подключить вызывает `NETunnelProviderManager`. Если пользователь выключил loft в Настройках, приложение показывает выкл.

Разрешение VPN — системный лист один раз. Дальше Подключить не спрашивает.

Разрешение камеры — системный лист при первом Сканировать (`NSCameraUsageDescription`). Фото — `PHPicker` (без полного доступа к медиатеке). Файлы: картинки, текст, YAML, `.loft`.

Схема URL `loft`: тап по `loft://…` предлагает импорт.

### Жесты списка

Словарь Почты / Файлов на телефоне. Список macOS держит призрак Править на строке; iOS добавляет свайп и долгое нажатие — указателя нет.

| Жест | Действие |
|------|----------|
| Тап | Открыть подключение (Правка). Подключает компактная кнопка Подключить; если жило другое подключение, оно сначала отключается. |
| Компактное Подключить / Отключить | Та же кнопка, что в списке macOS (`Подключить` / `Отключить`). |
| Свайп влево | Удалить, с листом подтверждения. |
| Свайп вправо | Править. |
| Долгое нажатие | Меню: Править; Экспорт `.loft`, если строка выбрана; Удалить. |
| Экспорт на выбранной строке | Лист: это подключение как `Name.loft`; QR `loft://` живого фронта; все подключения как `Family.loft`. Лист повторяет предупреждение про ключ. |

## 4. Визуал

Те же токены, что на macOS: Ink `#1A1714`, Lamp `#E8B84A`, Paper `#E8DFD2`, Avenir Next. Хром телефона в макете — loft (тёмная бумага), не серые группы iOS.

Шрифт: заголовки Demi, текст Regular, ключи SF Mono. В сети = окно лампы горит. Выкл = лампа погашена, каменная L.

Safe area: статус-бар + индикатор домой. Одна колонка. Большая Подключить / Отключить на доме — под большой палец. Панель вкладок **Дом · Подключения · Настройки** сидит над индикатором — на Доме, в Подключениях, в Настройках и на экранах, открытых из них (Журнал, О программе). Правка, Сканер и QR — модальные, без неё; Онбординг — во весь экран.

Сканер: тёмный видоискатель, угловые скобки цвета лампы, два действия под кадром (Из файла / Из Фото).

Тип VPN — **капсула** (заливка лампы на выбранном), вкладки Основные/Дополнительно и Настройки — тот же сегмент, что на macOS.
