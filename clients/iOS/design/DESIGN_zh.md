# loft · iOS 客户端

[English](DESIGN.md) · [Русский](DESIGN_ru.md) · **中文**

手机应用加一条 Packet Tunnel。标志、色板、Avenir Next：[`brand/`](../../../docs/brand/)。交互模型：[`index.html`](index.html)；每个状态都有自己的链接，比如 `index.html#edit-sstp`、`#settings-route`、`#home-off`（点到哪儿地址就跟到哪儿）。协议：[docs/protocol_zh.md](../../../docs/protocol_zh.md)。导入 URI：[docs/share_zh.md](../../../docs/share_zh.md)。

SwiftUI 容器在 [`../App/`](../App/)。Home 是 `HomeView`，用 Xcode Canvas `#Preview`（`Home · off` / `on` / `simple`；还有 connecting、ru、zh）。设置是 `SettingsView`（`Settings` / `Settings · ru` / `About`）：通用 / 路由 / 连接，语言芯片立刻通过 `LoftPrefs` 生效。活会话是 Network Extension 里的 Go，不是 `loft-front`。YAML 宿主 `ContentView` 留到有档案再换。

这个模型跟着 **正在出货的 macOS GUI**（`clients/macOS`、`L10n.swift`，状态 / 列表 / 编辑 / 设置 / 引导 / 日志 / 关于）落到手机上。文案、字段和信息架构跟那个客户端对齐。iOS 留一条 Packet Tunnel、相机扫描、列表滑动/长按、系统 VPN 那一行。不长 SOCKS 入站、Dock、登录项、也不开几条并行隧道。

---

## 1. 产品

入站是系统 VPN（Packet Tunnel）。一次一条配置：loft（`lt_…`，没有密码）、SSTP（用户 + 密码）或 VLESS（`vless://`）。

v1：磁盘上的命名连接，导入/导出 `.loft`，连接 / 断开，不要恢复直连，按协议列表分流。loft YAML 里 `select: auto`。一次一条隧道。

`.loft` 文件里是 **一条或多条连接**。类型可以混：`loft`、`sstp`、`vless`。界面里 loft 地址是字符串 `loft://`。规格：[docs/share_zh.md](../../../docs/share_zh.md)。

分享：扫二维码，或载入带 `loft://`、`sstp://`、`vless://` 或 `.loft` 的图片/文件。

iOS 设置里显示的就是应用拉起的那条 VPN。应用不替代设置。

Apple TV（tvOS 17+）是 iPhone GUI 之后同一条 Packet Tunnel。[计划](../PLAN.md) 第 6 阶段。这个模型是手机。

### 分流

沿用 macOS 的模型（macOS DESIGN §5）：**区域** 经 loft 或绕过 loft，**服务**（名称 + CIDR）只是属于某个区域，**排除** 是不写入路由、拉取列表后仍保留的 CIDR。内置区域 Local（绕过，局域网）和 Global（经 loft，`global.bat`），自己的区域在编辑器里加。iOS 上「经 loft」是 Packet Tunnel 的 `includedRoutes`，「绕过」是它的 `excludedRoutes`；隧道关着时本来就全部直连。没有 macOS 那种记住的直连下一跳。

入口：设置 → 路由 → 开关和金色的 **列表**。这些屏在设置标签里打开，顶上是 **‹ 设置** / **‹ 返回**。

| 屏 | 内容 |
|----|------|
| 列表 | 标题和同一个开关，一行说明（经 loft 进隧道，绕过直连）。**区域** + **区域** → 编辑器。区域胶囊带服务数。安静的一行 `Global · 经 loft`。搜索。行：名称、前几个 CIDR、网段数、来源（列表 / 自定义）；点一下编辑。一行 **排除项 · N ›**。**+ 添加**。底部 **导入 · 导出 · 规则集**。 |
| 网络 | 条目 路由 / 排除，网段或地址（编辑时每行一个 CIDR），服务，区域。添加 / 保存。 |
| 区域 | 行：名称、网段数 · 列表文件、方向、「内置」。**+ 添加区域**。 |
| 区域编辑 | 名称（内置的锁住）、方向 经 loft / 绕过 loft、列表地址 + **列表**、自动更新、保存；自己的区域有 删除区域（服务 → Global）。新区域同样的字段。 |
| 规则集 | 当前区域的列表地址 + **列表**、自动更新、上次拉取、立即更新。 |
| 目录 | loft-routes 列表：全球、俄罗斯、中国、伊朗、哈萨克斯坦、白俄罗斯；当前的高亮。点一下填入地址并返回。 |
| 导入 | 从文件（iOS 文件），识别出的格式和行数，区域，添加。 |
| 导出 | 所有区域写进一个 loft-routes 文件（区域在 `REM zone:`，服务名在注释里），示例，保存（分享页）。 |

**清理。** 删除立即生效。底部 snackbar 显示 5 秒：「已删除：YouTube · **撤销**」，点撤销恢复原样。除清空区域和清空排除项外，不弹确认框。

- 在服务行上**向左滑动**，露出红色 **删除**。
- **长按**一行进入选择模式。标题换成操作栏：**✕**、「已选 N 项」、**全选**（打开的区域里所有服务，再点取消）、**删除**。各行出现勾选圆圈，点按切换。
- 在 **网络** 屏，已有条目底部有 **删除服务**（排除项为 **删除排除项**）。屏幕关闭，出现 snackbar。
- 列表导航栏的 **⋯**：**选择**（同一选择模式）和 **清空区域**。对话框「清空 Global？」：**仅自己添加的 (N)** 和 **全部，包括列表 (M)**。「全部」会解除区域的列表：地址和自动更新关闭，否则下次更新服务又会回来。排除项保留。区域里没有来自列表的服务时，只有一行 **全部删除**。

来自列表的服务（来源「列表」）删除时不会无痕消失：它的网段移入该区域的排除项，否则下次更新又会加回来（macOS §5 的规则）。snackbar 会写明：「… · 列表网络已移入排除项」。自己添加的服务直接删除。

**排除项**有单独的屏，不混在服务列表里。服务列表下方有一行 **排除项 · N ›**。「Global · 排除项」屏（顶上 **‹ 返回**）：说明「这些网络不会加入路由，列表更新时也不会恢复」，每行一个 CIDR（等宽）、右侧是服务名，点按在网络屏编辑。**向左滑动** 露出 **恢复**：删除该排除项，网络会随下次列表更新回来。**+ 添加** 打开网络屏并选中「排除」。底部 **清空排除项**，带对话框。

## 3. iOS 外壳

不要改 设置 → VPN 的样子。模型只说明 **loft** 在 *他们* 的 VPN 列表里长什么样：状态 Connected，类型 loft，开关是系统隧道，不是我们应用里第二个开关。

连接 调 `NETunnelProviderManager`。用户在设置里关了 loft，应用显示已关闭。

VPN 权限是系统那张页，一次。之后连接 不再问。

相机权限是第一次打开扫描时的系统页（`NSCameraUsageDescription`）。照片走 `PHPicker`（不要完整相册权限）。文件选择器认图片、文本、YAML、`.loft`。

URL scheme `loft`，点 `loft://…` 会提议导入。

### 列表手势

手机上用邮件 / 文件那套词。macOS 列表行上有淡色编辑；iOS 加上滑动和长按，因为没有指针。

| 手势 | 动作 |
|---------|--------|
| 点一下 | 打开这条连接（编辑）。连接靠紧凑的「连接」按钮；另一条开着的话先断开。 |
| 紧凑打开 / 断开 | 跟 macOS 列表按钮一样（`打开` / `断开`）。 |
| 向左滑 | 删除，带确认页。 |
| 向右滑 | 编辑。 |
| 长按 | 菜单：编辑；这条选中时导出 `.loft`；删除。 |
| 选中行上的导出 | 页：这条连接存成 `Name.loft`；活前置的二维码 `loft://`；所有连接存成 `Family.loft`。页上再写一遍导出提醒。 |

## 4. 视觉

跟 macOS 同一套 loft 记号：Ink `#1A1714`，Lamp `#E8B84A`，Paper `#E8DFD2`，Avenir Next。模型里的手机外壳是 loft（深色纸），不是 iOS 分组灰。

字体：标题 Demi，正文 Regular，密钥 SF Mono。已连接 = 灯窗亮。已关闭 = 灯灭，石头色 L。

安全区：状态栏 + Home 指示条。一列。拇指够得到：连接 / 断开是主页上的大控件。标签栏 **主页 · 连接 · 设置** 坐在 Home 指示条上，出现在主页、连接、设置以及从设置进入的屏（日志、关于）。编辑、扫描和分享二维码是模态，没有标签栏；引导是全屏。

扫描：深色取景，灯色角括号，取景下面两个动作（从文件 / 从照片）。

VPN 类型是 **胶囊**（选中的类型用灯色填），连接/高级和设置页签跟 macOS 同一套分段。
