# loft · клиент Sailfish OS

[English](DESIGN.md) · **Русский** · [中文](DESIGN_zh.md)

Приложение для телефона и строка оверлея ConnMan. Знак, палитра и Avenir Next: [`brand/`](../../../docs/brand/). Интерактивные макеты: [`index.html`](index.html) (Sailfish OS, классический Silica) и [`aurora.html`](aurora.html) (ОС Аврора 5, §7); сегментный переключатель **Sailfish OS | ОС Аврора** в боковой панели макета (как и переключатель языка) переключает между ними, сохраняя текущий экран. У каждого состояния своя ссылка, например `index.html#edit-sstp`, `#settings-route`, `#home-off`, `#home-pulley` (адрес меняется при переходах). Протокол: [docs/protocol_ru.md](../../../docs/protocol_ru.md). URI импорта: [docs/share_ru.md](../../../docs/share_ru.md).

Контейнер QML — в [`../qml/`](../qml/). Рабочую сессию ведёт `loft-front`, а не gomobile. Адаптер — **Qt 5 / QML Silica**; макет — HTML, GUI — страницы Silica. ОС Аврора — пакет OMP из того же дерева: `aurora/` (`app.loft.aurora`); RPM для Sailfish — `sailfish/` (`harbour-loft`).

Макет переносит на телефон **рабочий GUI macOS** (`clients/macOS`, `L10n.swift`, статус / список / правка / настройки / онбординг / журнал / о программе) — через макет iOS, на основе которого он сделан. Тексты, поля и IA совпадают с этим клиентом. На Sailfish остаются один туннель ConnMan, сканер камеры, долгое нажатие в списке, обложка и системная строка VPN. SOCKS-входа, Dock, login item и нескольких одновременных туннелей здесь нет.

---

## 1. Продукт

Локальным входом служит системная строка оверлея (ConnMan). Одновременно активен один профиль: loft (`lt_…`, пароля нет), SSTP (логин + пароль), VLESS (`vless://`) или Trojan (`trojan://`).

v1: именованные подключения на диске, импорт/экспорт `.loft`, Подключить / Отключить, удержание, раздельная маршрутизация по спискам протокола. `select: auto` внутри YAML loft. Одновременно работает один туннель.

Файл `.loft` содержит **одно или несколько подключений**. Типы можно смешивать: `loft`, `sstp`, `vless`, `trojan`. В интерфейсе адрес loft записывается строкой `loft://`. Спецификация: [docs/share_ru.md](../../../docs/share_ru.md).

Обмен: отсканировать QR-код или загрузить картинку/файл с `loft://`, `sstp://`, `vless://`, `trojan://` или `.loft`.

Настройки → VPN показывают ту же строку ConnMan **Loft**, которую поднимает плагин. Приложение не подменяет Настройки.

## 2. Экраны

Те же экраны, что и окна macOS, но в одну колонку под большой палец и в оформлении Silica: без панели вкладок, со стеком страниц, вытягиваемыми меню, диалогом и отложенным действием (remorse).

**Навигация.** Дом — корневая страница. В его **вытягиваемом меню** (pulley, тянуть вниз) — Настройки, Подключения, Сканировать QR-код; светящаяся линия вверху страницы означает, что у неё есть такое меню. Остальные страницы кладутся в стек: индикатор назад **‹** слева вверху (и свайп назад) возвращает на шаг. Из Подключений и Настроек «назад» ведёт на Дом. Заголовки страниц — `PageHeader` Silica: выровнены по правому краю и окрашены цветом подсветки (лампой). У Подключений, Правки, Настроек, Журнала и Списков действия страницы тоже вынесены в вытягиваемое меню; ряда кнопок действий внизу нет ни на одной странице.

### Раздельная маршрутизация

Модель macOS (DESIGN macOS §5): **зона** идёт через loft или в обход, **сервис** (имя + CIDR) только принадлежит зоне, **исключение** — CIDR, который не входит в зону и сохраняется при обновлении списка. Встроенные зоны — Local (в обход, LAN) и Global (через, `global.bat`); свои создаются в редакторе. На Sailfish «через loft» означает маршруты на строке ConnMan Loft, а «в обход» остаётся на системном маршруте по умолчанию; пока туннель выключен, всё и так идёт напрямую. Запоминания прямого хопа, как на macOS, нет.

**Зона Block.** Третья встроенная зона, рядом с Local и Global, без списка по умолчанию. Направление зоны — одно из трёх: **Через loft / В обход loft / Блокировать**; любая своя зона тоже может блокировать. Сети такой зоны заводятся в туннель, и клиент сам сразу отвечает отказом: TCP — сбросом соединения, остальное — ICMP «недоступен». Приложения не ждут тайм-аута. Блокировка действует только при включённом туннеле, как и вся раздельная маршрутизация. Исключения зоны не блокируются. В строке зоны и в списке зон — «Блокируется», под ней пояснение: «Пока включён loft, соединения к сетям этой зоны сразу получают отказ, а её домены не резолвятся.»

**Домены и местный DNS.** У сервиса, кроме сетей, есть **Домены** (домен включает поддомены; сервис может состоять из одних доменов). DNS отвечает сам клиент — резолвер в туннеле, который ОС получает вместо DNS ноды: имена из зон «в обход» он спрашивает у **местного DNS** (запрос идёт мимо туннеля), имена из зоны Block (и любой блокирующей) сразу получают NXDOMAIN, всё остальное уходит в DNS ноды. Настройки → Маршрут → **Местный DNS**: **Системный** (DNS сети, запомненный до подключения; по умолчанию), **Свой адрес** (например `77.88.8.8`) или **DoH** (URL). Работает только при включённом туннеле. В строке сервиса — «2 сети · 3 домена»; у сервиса из одних доменов вместо CIDR показаны первые домены. В редакторе «Сеть» поле **Домены** идёт после сетей, у исключения его нет.

**Профили маршрутов.** Зоны, сервисы, исключения и местный DNS вместе — это профиль; активен один. Вверху «Списков» строка **Профиль · RU напрямую ›** (у профиля оператора справа «оператор»), она открывает экран **Профили маршрутов**: строки профилей с пометкой источника («свой», «от оператора · Home · обновлён сегодня», «из ссылки») и «✓ активен»; тап делает профиль активным. Профиль оператора приходит с ноды внутри сессии (протокол §10.3, `lists_inline`) и обновляется сам, поэтому он **только для чтения**: в «Списках» нет добавления, удаления, очистки, импорта и редактора зон, поля в правке закрыты, над зонами — «Профиль оператора — только чтение: он обновляется с ноды» и **Сделать копию**. Копия становится своим профилем с именем «RU напрямую (копия)», её сервисы — «свои», и она сразу активна. **+ Импорт профиля** — ссылка `loft://routes/…` или файл `.loft` с профилем; профиль добавляется в список, свои правила не трогаются.

| Зона | Имя (у встроенной закрыто), направление Через loft / В обход loft / Блокировать, адрес списка + **Списки**, автообновление, Сохранить; у своей — Удалить зону (сервисы → Global). Новая зона — те же поля. |
| Репозиторий | Адрес списка открытой зоны + **Списки**, автообновление, последнее обновление, Обновить сейчас. |
| Каталог | Списки loft-routes: Мир, Россия, Китай, Иран, Казахстан, Беларусь; текущий подсвечен. Тап ставит адрес и возвращает назад. |
| Импорт | Из файла (Документы), распознанный формат и число строк, зона, Добавить. |
| Экспорт | Все зоны в одном файле loft-routes (зона — в `REM zone:`, имя сервиса — в комментарии), образец, Сохранить («Поделиться»). |

**Удаление маршрутов** — тоже отложенное действие, но изменение видно сразу: строка пропадает, вверху полоса «Удаление YouTube» (несколько — «Удаление: 3», зона — «Очистка Global», исключение — «Возврат 162.159.0.0/16») с отсчётом 5 с; тап по полосе возвращает всё как было (`#split-remorse`). Сервис из списка при удалении оставляет свои сети в исключениях зоны, иначе следующее обновление вернёт его. Свои сервисы удаляются насовсем.

## 3. Системный интерфейс Sailfish

Не перекрашивать Настройки → VPN. Макет показывает, как **Loft** выглядит в *их* списке ConnMan: статус Подключено, тип loft, тумблер — это строка ConnMan Loft, а не второй выключатель в нашем приложении.

Наше Подключить пишет YAML и просит ConnMan поднять подключение loft. Если плагина нет, приложение запускает `loft-front` с SOCKS на loopback. Если пользователь выключил Loft в разделе Настройки → VPN, приложение показывает состояние «выкл».

Согласие на VPN запрашивается системным диалогом ConnMan один раз, если ОС этого потребует. Дальше Подключить ничего не спрашивает.

Разрешение на камеру запрашивается системным листом при первом сканировании. Для файлов нужно разрешение на Документы; диалог выбора принимает картинки, текст, YAML, `.loft`. Галерея открывается системным диалогом выбора.

Схема URL `loft`: тап по `loft://…` предлагает импорт.

Удержание реализовано так: маршрут по умолчанию ConnMan остаётся занятым. В текстах — *маршрут* / *прямой интернет*.

Обложка — то, что видно на главном экране: знак-лампа, имя, состояние, overlay IP, одно действие обложки (значок питания), которое подключает / отключает.

### Жесты списка

В списке macOS на строке есть «призрачная» кнопка Править; на Sailfish вместо неё долгое нажатие, потому что указателя нет. Свайп-действий нет; добавление вынесено в вытягиваемое меню, а не на кнопку.

| Жест | Действие |
|------|----------|
| Тап | Открыть подключение (Правка). Подключает компактная кнопка Подключить; если было активно другое подключение, оно сначала отключается. |
| Компактное Подключить / Отключить | Та же кнопка, что в списке macOS (`Подключить` / `Отключить`). |
| Долгое нажатие | Контекстное меню под строкой (ContextMenu Silica), строки ниже сдвигаются вниз: Править; Экспорт, если строка выбрана; Удалить (отложенное действие). |
| Потянуть вниз | Вытягиваемое меню: Сканировать QR-код · Вставить ссылку · Из файла · Вручную. |
| Экспорт на выбранной строке | Страница **Экспорт Home**: это подключение как `Name.loft`; QR `loft://` живого фронта; все подключения как `Family.loft`. Страница повторяет предупреждение про ключ. |

## 4. Визуал

Те же токены loft, что на iOS, Android и macOS: Ink `#1A1714`, Lamp `#E8B84A`, Paper `#E8DFD2`, Avenir Next. Оформление телефона в макете — loft (тёмная бумага). Вытягиваемое меню, стек страниц, шапка диалога, отложенное действие и обложка — из Silica; Material и навигацию iOS не копируем.

Шрифт: заголовки Demi, текст Regular, ключи SF Mono. В сети = окно лампы горит. Выкл = лампа погашена, каменная L.

Safe area: статус-бар + вытягиваемое меню. Одна колонка. Большая кнопка Подключить / Отключить на Доме — в зоне большого пальца. Панели вкладок нет: Дом — корень, Подключения и Настройки — из его меню, всё остальное кладётся в стек с **‹** слева вверху. Заголовки страниц — справа, цветом подсветки. Правка — диалог с Отмена / Сохранить вверху; Онбординг — во весь экран.

Сканер: тёмный видоискатель, угловые скобки цвета лампы, два действия под кадром (Из файла / Из галереи).

Тип VPN — **капсула** (заливка лампы на выбранном), вкладки Основные/Дополнительно и Настройки — тот же сегмент, что на macOS.

Системные поверхности в макете (обложка, Настройки → VPN) сохраняют штатное оформление, чтобы граница продукта была видна.

## 7. ОС Аврора 5

Макет: [`aurora.html`](aurora.html). То же дерево пакета, что у Sailfish (`aurora/`, `app.loft.aurora`). По [примечаниям к выпуску ОС Аврора 5.0](https://developer.auroraos.ru/release_notes/os_5.0.0.60) системные приложения перешли с вытягиваемых меню и меню действий на **AppBar** с **PopupMenu**. Макет следует этому; остальное — как в макете Sailfish.

| Экран | Аврора 5 |
|-------|----------|
| Дом | AppBar вверху: кнопки-иконки **Подключения**, **Настройки** и **Сканировать QR-код**; на Доме один такой пункт, поэтому он прямо на панели, без PopupMenu. Вытягиваемого меню и светящейся линии нет. |
| Подключения | AppBar: **‹**, заголовок «Подключения», **+** → PopupMenu: **Сканировать QR-код · Вставить ссылку · Из файла · Вручную** (`#list-menu`). |
| Долгое нажатие | Как на Sailfish: контекстное меню (Править / Экспорт / Удалить) открывается под своей строкой и сдвигает строки ниже вниз. |
| Правка, Настройки, Журнал, Списки | Вместо вытягиваемых меню Sailfish — кнопка **⋮** в AppBar с PopupMenu поверх затемнённой страницы. Правка: ⋮ слева в строке заголовка, потому что заголовок по правому краю; Настройки, Журнал, Списки: ⋮ справа вверху, в строке «назад». В ссылках `-menu` вместо `-pulley` (`#edit-menu`, `#settings-menu`, `#journal-menu`, `#list-menu`). Списки: ⋮ → **Выбрать · Репозиторий · Экспорт · Импорт · Зоны · Очистить зону**; Сеть: ⋮ → **Удалить**; Исключения: ⋮ → **Очистить исключения**. |
| Онбординг | Подсказка про согласие: «Если Аврора спросит разрешение на VPN — нажмите „Разрешить“. Это один раз.» |
| Остальное | Как в макете Sailfish: шапка диалога Правки (Отмена / Сохранить), отложенное действие, заголовки страниц, страница Экспорт, баннер удержания, обложка, Настройки → VPN. Раздел навигации макета — **Аврора**. |

В Авроре 5 есть ещё **SplitView** для планшетов и перерисованные обложки; макет их не показывает.
