# loft · клиент Sailfish OS

[English](DESIGN.md) · **Русский** · [中文](DESIGN_zh.md)

Приложение и строка оверлея ConnMan. Марка, палитра и Avenir Next: [`brand/`](../../../docs/brand/). Интерактивные макеты: [`index.html`](index.html) (Sailfish OS, классический Silica) и [`aurora.html`](aurora.html) (ОС Аврора 5, §7); сегментный переключатель **Sailfish OS | ОС Аврора** в боковой панели макета, как переключатель языка, ведёт между ними и сохраняет экран. У каждого состояния своя ссылка, например `index.html#edit-sstp`, `#settings-route`, `#home-off`, `#home-pulley` (адрес меняется по мере кликов). Протокол: [docs/protocol_ru.md](../../../docs/protocol_ru.md). URI импорта: [docs/share_ru.md](../../../docs/share_ru.md).

Контейнер QML — в [`../qml/`](../qml/). Живая сессия — `loft-front`, не gomobile. Адаптер — **Qt 5 / QML Silica**; макет — HTML, GUI — страницы Silica. ОС Аврора — пакет OMP из того же дерева: `aurora/` (`app.loft.aurora`); RPM для Sailfish — `sailfish/` (`harbour-loft`).

Макет следует **живому GUI macOS** (`clients/macOS`, `L10n.swift`, статус / список / правка / настройки / онбординг / журнал / о программе) на телефоне — через макет iOS, из которого он сделан. Тексты, поля и IA — как у того клиента. Sailfish держит один туннель ConnMan, сканер камеры, долгое нажатие в списке, обложку и системную строку VPN. Не появляется SOCKS-вход, Dock, login item и несколько туннелей сразу.

---

## 1. Продукт

Локальный вход — системная строка оверлея (ConnMan). Один профиль сразу: loft (`lt_…`, пароля нет), SSTP (логин + пароль), VLESS (`vless://`) или Trojan (`trojan://`).

v1: именные подключения на диске, импорт/экспорт `.loft`, Подключить / Отключить, удержание, раздельная маршрутизация по спискам протокола. `select: auto` внутри YAML loft. Туннель один.

Файл `.loft` держит **одно или несколько подключений**. Типы смешиваются: `loft`, `sstp`, `vless`, `trojan`. Адрес loft в UI — строка `loft://`. Спецификация: [docs/share_ru.md](../../../docs/share_ru.md).

Поделиться: сканер QR-кода или картинка/файл с `loft://`, `sstp://`, `vless://`, `trojan://` или `.loft`.

Настройки → VPN показывают ту же строку ConnMan **Loft**, которую поднимает плагин. Приложение не подменяет Настройки.

## 2. Экраны

Те же комнаты, что окна macOS, в одну колонку под большой палец, в хроме Silica: без панели вкладок, стек страниц, вытягиваемые меню, диалог и отложенное действие (remorse).

**Навигация.** Дом — корневая страница. Его **вытягиваемое меню** (pulley, тянуть вниз): Настройки, Подключения, Сканировать QR-код; светящаяся линия вверху страницы значит, что у неё есть такое меню. Остальные страницы кладутся в стек: индикатор назад **‹** слева вверху (и свайп назад) возвращает на шаг. Из Подключений и Настроек назад — на Дом. Заголовки страниц — `PageHeader` Silica: по правому краю, цветом подсветки (лампой). У Подключений, Правки, Настроек, Журнала и Списков действия страницы тоже в вытягиваемом меню; ряда кнопок действий внизу нет ни на одной странице.

**Отложенное действие (remorse).** Удаление подключения, сброс по умолчанию, сброс маршрутов и очистка журнала не открывают лист подтверждения. Полоса вверху называет действие («Удаление Home», «Сбросить», «Очистить»), под ней обратный отсчёт и «Нажмите, чтобы отменить»; когда отсчёт кончился, действие выполняется.

**Упрощённый интерфейс** (Настройки → Общие): дом — марка, пилюля, Подключить / Отключить; вытягиваемое меню остаётся. Карточки и искра скрыты. В списке остаются Подключить/Отключить и имя. Настройки полные.

В навигации макета ещё есть **Дом · без интернета**, **Экспорт**, **Правка · меню**, **Настройки · меню** и **Журнал · меню**. В навигации макета есть раздел платформы **Sailfish**: **Обложка** и **Настройки → VPN**.

Хром только macOS, которого в макете нет: поповер строки меню, карточка и порт SOCKS5, значок Dock, login item, несколько исходящих сразу, пластина drag-and-drop.

### Раздельная маршрутизация

Модель macOS (DESIGN macOS §5): **зона** идёт через loft или в обход, **сервис** (имя + CIDR) только принадлежит зоне, **исключение** — CIDR, который не входит в зону и сохраняется при обновлении списка. Встроенные зоны Local (в обход, LAN) и Global (через, `global.bat`), свои — из редактора. На Sailfish «через loft» — маршруты на строке ConnMan Loft, «в обход» остаётся на системном маршруте по умолчанию; пока туннель выключен, всё и так идёт напрямую. Снимка прямого хопа, как на macOS, нет.

Вход: Настройки → Маршрут → тумблер и золотая **Списки**. Экраны кладутся в стек Настроек, вверху **‹**.

| Экран | Что |
|-------|-----|
| Списки | Заголовок отдельно; под ним строка-тумблер **Включена** / **Выключена** с подписью (через — в туннель, в обход — напрямую). Вытягиваемое меню: **Репозиторий · Экспорт · Импорт · Зоны**. **Зона** + **Зоны** → редактор. Вкладки-капсулы зон с числом сервисов. Тихая строка `Global · Через loft`. Поиск. Строки: имя, первые CIDR, число сетей, источник (список / свои / исключ.); тап — правка. **+ Добавить**. |
| Сеть | Запись Маршрут / Исключение, сеть или адрес (в правке — по строке на CIDR), сервис, зона. Добавить / Сохранить. |
| Зоны | Строки: имя, число сетей · файл списка, направление, «Встроенная». **+ Добавить зону**. |
| Зона | Имя (у встроенной закрыто), направление Через loft / В обход loft, адрес списка + **Списки**, автообновление, Сохранить; у своей — Удалить зону (сервисы → Global). Новая зона — те же поля. |
| Репозиторий | Адрес списка открытой зоны + **Списки**, автообновление, последнее обновление, Обновить сейчас. |
| Каталог | Списки loft-routes: Мир, Россия, Китай, Иран, Казахстан, Беларусь; текущий подсвечен. Тап ставит адрес и возвращает назад. |
| Импорт | Из файла (Документы), распознанный формат и число строк, зона, Добавить. |
| Экспорт | Все зоны в одном файле loft-routes (зона — в `REM zone:`, имя сервиса — в комментарии), образец, Сохранить («Поделиться»). |

## 3. Хром Sailfish

Не перекрашивать Настройки → VPN. Макет показывает, как **Loft** выглядит в *их* списке ConnMan: статус Подключено, тип loft, тумблер — строка ConnMan Loft, не второй выключатель в нашем приложении.

Наше Подключить пишет YAML и просит ConnMan поднять подключение loft. Если плагина нет, приложение запускает `loft-front` с SOCKS на loopback. Если пользователь выключил Loft в Настройки → VPN, приложение показывает выкл.

Согласие на VPN — системный запрос ConnMan один раз, если ОС спросит. Дальше Подключить не спрашивает.

Разрешение камеры — системный лист при первом Сканировать. Файлы: разрешение на Документы; выбор принимает картинки, текст, YAML, `.loft`. Галерея — системный выбор.

Схема URL `loft`: тап по `loft://…` предлагает импорт.

Удержание ложится на то, что маршрут по умолчанию ConnMan остаётся занятым. В текстах — *маршрут* / *прямой интернет*.

Обложка — то, что видно на главном экране: знак-лампа, имя, состояние, overlay IP, одно действие обложки (значок питания), которое подключает / отключает.

### Жесты списка

Список macOS держит призрак Править на строке; Sailfish берёт долгое нажатие — указателя нет. Свайп-действий нет; добавление — в вытягиваемом меню, не на кнопке.

| Жест | Действие |
|------|----------|
| Тап | Открыть подключение (Правка). Подключает компактная кнопка Подключить; если жило другое подключение, оно сначала отключается. |
| Компактное Подключить / Отключить | Та же кнопка, что в списке macOS (`Подключить` / `Отключить`). |
| Долгое нажатие | Контекстное меню под строкой (ContextMenu Silica), строки ниже сдвигаются вниз: Править; Экспорт, если строка выбрана; Удалить (отложенное действие). |
| Потянуть вниз | Вытягиваемое меню: Сканировать QR-код · Вставить ссылку · Из файла · Вручную. |
| Экспорт на выбранной строке | Страница **Экспорт Home**: это подключение как `Name.loft`; QR `loft://` живого фронта; все подключения как `Family.loft`. Страница повторяет предупреждение про ключ. |

## 4. Визуал

Те же токены loft, что на iOS, Android и macOS: Ink `#1A1714`, Lamp `#E8B84A`, Paper `#E8DFD2`, Avenir Next. Хром телефона в макете — loft (тёмная бумага). Вытягиваемое меню, стек страниц, шапка диалога, отложенное действие и обложка — из Silica; Material и навигацию iOS не копируем.

Шрифт: заголовки Demi, текст Regular, ключи SF Mono. В сети = окно лампы горит. Выкл = лампа погашена, каменная L.

Safe area: статус-бар + вытягиваемое меню. Одна колонка. Большая Подключить / Отключить на доме — под большой палец. Панели вкладок нет: Дом — корень, Подключения и Настройки — из его меню, всё остальное кладётся в стек с **‹** слева вверху. Заголовки страниц — справа, цветом подсветки. Правка — диалог с Отмена / Сохранить вверху; Онбординг — во весь экран.

Сканер: тёмный видоискатель, угловые скобки цвета лампы, два действия под кадром (Из файла / Из галереи).

Тип VPN — **капсула** (заливка лампы на выбранном), вкладки Основные/Дополнительно и Настройки — тот же сегмент, что на macOS.

Системные поверхности в макете (обложка, Настройки → VPN) держат штатный хром, чтобы граница продукта была видна.

Общие строки — кнопки, настройки, маршруты — берутся из `clients/macOS/lang/*.lang` и звучат одинаково на macOS, iOS и Sailfish. ## 7. ОС Аврора 5

Макет: [`aurora.html`](aurora.html). То же дерево пакета, что у Sailfish (`aurora/`, `app.loft.aurora`). По [примечаниям к выпуску ОС Аврора 5.0](https://developer.auroraos.ru/release_notes/os_5.0.0.60) системные приложения перешли с вытягиваемых меню и меню действий на **AppBar** с **PopupMenu**. Макет следует этому; остальное — как в макете Sailfish.

| Экран | Аврора 5 |
|-------|----------|
| Дом | AppBar вверху: кнопки-иконки **Подключения**, **Настройки** и **Сканировать QR-код**; на Доме один такой пункт, поэтому он прямо на панели, без PopupMenu. Вытягиваемого меню и светящейся линии нет. |
| Подключения | AppBar: **‹**, заголовок «Подключения», **+** → PopupMenu: **Сканировать QR-код · Вставить ссылку · Из файла · Вручную** (`#list-menu`). |
| Долгое нажатие | Как на Sailfish: контекстное меню (Править / Экспорт / Удалить) открывается под своей строкой и сдвигает строки ниже вниз. |
| Правка, Настройки, Журнал, Списки | Вытягиваемые меню Sailfish — кнопка **⋮** в AppBar с PopupMenu поверх затемнённой страницы. Правка: ⋮ слева в строке заголовка, потому что заголовок по правому краю; Настройки, Журнал, Списки: ⋮ справа вверху, в строке «назад». В ссылках `-menu` вместо `-pulley` (`#edit-menu`, `#settings-menu`, `#journal-menu`, `#list-menu`). |
| Онбординг | Подсказка про согласие: «Если Аврора спросит разрешение на VPN — нажмите „Разрешить“. Это один раз.» |
| Остальное | Как в макете Sailfish: шапка диалога Правки (Отмена / Сохранить), отложенное действие, заголовки страниц, страница Экспорт, баннер удержания, обложка, Настройки → VPN. Раздел навигации макета — **Аврора**. |

В Авроре 5 есть ещё **SplitView** для планшетов и перерисованные обложки; макет их не показывает.
