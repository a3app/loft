# loft lists

**English** · [Русский](README_ru.md) · [中文](README_zh.md)

Named Keenetic / loft-routes files the macOS client can attach to a zone. Live lists and the picker catalog live in [a3app/loft-routes](https://github.com/a3app/loft-routes). Files here are bundled stubs.

```
https://raw.githubusercontent.com/a3app/loft-routes/main/catalog.json
https://raw.githubusercontent.com/a3app/loft-routes/main/global.bat
https://raw.githubusercontent.com/a3app/loft-routes/main/ru.bat
https://raw.githubusercontent.com/a3app/loft-routes/main/cn.bat
https://raw.githubusercontent.com/a3app/loft-routes/main/ir.bat
https://raw.githubusercontent.com/a3app/loft-routes/main/kz.bat
https://raw.githubusercontent.com/a3app/loft-routes/main/by.bat
```

A zone has one URL. Direction lives on the zone, not on the file: through loft, around loft, or block (the built-in Block zone, no list by default). `REM zone:` is a hint for import.

| File | Typical zone |
|------|----------------|
| `global.bat` | Global (through loft) |
| `ru.bat` | Local (around loft) |
| `cn.bat` | Local (around loft) |
| `ir.bat` | Local (around loft) |
| `kz.bat` | Local (around loft) |
| `by.bat` | Local (around loft) |
